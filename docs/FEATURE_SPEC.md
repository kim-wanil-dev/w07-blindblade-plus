# 기능 명세

## 현재 정식 게임 흐름

빌드 씬은 타이틀, 온보딩, 대숲 1막, 비 내리는 2막 순서로 등록되어 있다. 신규 게임은 타이틀에서 온보딩을 거쳐 BambooStage1과 RainyTwinBoss를 진행하고 게임 클리어 화면으로 이어진다. 저장된 진행 정보가 있으면 이어 하기와 보스 체크포인트 재도전 경로가 적용된다.

| 순서 | 빌드 씬 | 현재 역할 |
| --- | --- | --- |
| 0 | IntroScene | 시작·이어 하기·설정 메뉴 |
| 1 | Onboarding | 본편 입력과 전투를 안내하는 5단계 온보딩 |
| 2 | BambooStage1 | 1막 일반 웨이브와 사운드 중심 보스전 |
| 3 | RainyTwinBoss | 2막 일반 웨이브와 쌍둥이 보스전 |

두 일반 웨이브의 현재 처치 목표는 각각 100명이다. 스폰 수치와 스폰 선택은 씬 저장값을 기준으로 하며, 세부값은 [대숲 방어](features/대숲_방어.md), [대숲 스테이지 1](features/대숲_스테이지1.md), [비 내리는 스테이지 2](features/비_스테이지2.md)에 정리한다.

## 게임 내 표시 용어

| 기존 표현 | 현재 게임 화면과 문서의 표현 |
| --- | --- |
| 플레이어의 돌진 공격 | 발도 |
| 수비·가드 | 막기 |
| 패리·패링·퍼펙트 패링 | 쳐내기 |
| 플레이어의 돌진 이동 | 회피 |
| 쳐내기 후 검기 발사·강화 공격 | 일섬 |
| 궁극기 | 거합 |

적의 돌진 패턴, 일반 검기 투사체, 코드 식별자와 이벤트 이름은 원래 의미를 유지한다.

## 명세 관리 규칙

- 기능의 현재 동작·조건·구현 상태를 기록한다. 과거 변경 기록은 기능 명세에 추가하지 않는다.
- 기능 명세는 docs/features/기능명.md에 둔다.
- 관련 코드 경로, 클래스·메서드와 책임을 기록한다.
- 확인하지 못한 동작은 미확인으로 표시하고, 확인하지 않은 기능의 설명은 추측으로 단정하지 않는다.
- 관련 기능과 공유하는 상태·연결 관계를 기록한다.
- 새 기능 명세를 만들거나 기존 기능을 수정하면 이 목록의 분류와 링크를 함께 갱신한다.
