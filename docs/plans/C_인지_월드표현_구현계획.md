## 확정 요구사항

### 적 거리 인지

- 기본 인지 거리: 12m. Inspector에서 조절한다.
- 거리 기준: 플레이어 루트와 적 루트의 XZ 수평 거리.
- 우선순위: 개체별 지정값 → 유형별 지정값 → 공통 기본값.
- 일반형·돌진형은 처음에는 유형별 덮어쓰기를 끄고 공통값을 사용한다.
- 다른 프리팹, 동일 프리팹의 일반형·돌진형, 개체별 지정값을 지원한다.
- Play 중 개체의 Inspector 값 변경은 즉시 반영한다. 최종 거리와 설정 출처를 진단 표시한다.
- 재사용 시 이전 생명의 런타임 지정값을 초기화하고 프리팹 기본값과 새 유형·개체 설정을 적용한다.
- 거리 0m는 평상시 거리 인지 없음이다. 보상 파동으로는 공개할 수 있다.
- 마지막 1m에서 페이드한다. 인지 거리가 1m보다 작으면 페이드 폭을 인지 거리 이하로 제한한다.
- 인지 범위 안의 적은 대나무·벽 뒤에서도 표시한다.
- 표시 제어로 적 루트·Collider·이동·공격 컴포넌트를 끄지 않는다.

### 화면 판정과 투사체

- 대상 외형 일부가 화면에 들어오면 화면 안으로 판단한다.
- 표시 자격이 있는 대상은 화면 안에서 월드 표현, 화면 밖에서 방향 UI를 사용한다.
- 화면 경계 전환에 여유를 두어 반복 전환을 줄인다. 출발값은 화면 폭·높이의 2%이며 Inspector에서 조절한다.
- 적대 수리검은 생성 직후부터 거리 제한 없이 표시 자격을 갖는다.
- 반사 수리검은 월드에서 흰색으로 표시하고 위협 방향 UI에서 제외한다.
- 플레이어를 통과한 적대 수리검은 해당 생명의 남은 수명 동안 방향 UI에서 제외한다. 화면에 들어오면 월드 표현은 유지한다.
- C는 표시 결과를 공급하고 D가 UI를 그린다. UI에서 거리·시야를 독립적으로 재판정하지 않는다.

### 색상

- 적과 적대 수리검은 동일한 공통 거리 색상 규칙을 사용한다.
- 색상 기준은 개체별 인지 반경과 분리한다. 같은 거리에 있는 대상은 같은 색상이다.
- 출발값: 3m 이하 붉은색 RGB(1, 0.1, 0.06), 12m 이상 흰색 RGB(1, 1, 1).
- 색상과 거리 구간·변화 곡선은 Inspector에서 조절한다. 별도의 시간 지연 없이 현재 거리를 반영한다.
- 거리에 따른 별도 투명도 감소는 없다. 적은 인지 경계에서만, 발소리는 수명에 따라 페이드한다.
- 위협은 외곽선만 표시한다. 사용자 화면 확인 후 내부 채움 출발값을 0.6에서 0으로 변경했다. Settings의 Fill Opacity로 내부 채움을 다시 조절할 수 있고, 활성화하면 대상 색상을 공유한다.
- 반사체의 기본색은 흰색으로 구분한다.
- 화면에서 위협끼리 겹치면 카메라에 가까운 대상이 앞에 보이도록 한다. 대나무·벽 차폐를 무시하는 정책과 별개다.

### 발소리 후보

- 기존 EnemyFootsteps.Footstep 위치 이벤트를 재사용한다.
- 인지 거리 출발값: 20m, 현재 적 루트와 관측자 루트의 XZ 수평 거리. 적 외형 인지 거리와 별도 설정이며 이 범위 안에서만 UI를 허용한다.
- 적이 실제로 화면에 표시되는 경우 발소리 UI를 숨긴다. 화면 안이어도 적 외형이 인지 범위 밖이면 안내를 허용한다.
- 총수명 0.8초, 마지막 0.3초 페이드. 모두 게임 시간 기준이다.
- 별도 후보 개수 제한을 두지 않고 적마다 최신 후보 하나를 보관한다.
- 후속 사용자 결정: Origin·발생 시각은 새 발걸음에서 고정 기록하고, UI 표시 위치·방향·색상·청각 거리는 D 방식처럼 적의 현재 Transform을 따라간다. 발생 위치 고정 표시 계획을 대체한다.
- 총수명·페이드 설정은 사용자 결정에 따라 새 발걸음에서 복사한다. 진행 중 후보에는 이전 값을 유지하며 청각 범위·색상은 즉시 반영한다.
- 사망·비활성화·수명 만료 시 정리한다. 재사용된 생명과 이전 후보를 섞지 않는다.
- 음향 설정이 꺼져 있어도 발걸음 사건의 시각 안내는 제공한다.
- 현재 거리가 20m 밖이면 숨기되 후보 수명 안에 재진입하면 재표시한다.

### 전집중·보상 파동

- 플레이어가 웅크리기로 능동 발동하는 반복 파동을 제거한다. 해당 입력 연결은 A 소유 파일에 있다.
- 퍼펙트 패링: 성공 확정으로 강화 준비·불릿 타임이 시작되는 순간 한 번 발동한다. 2026-10-14 사용자가 이전 설명을 정정하고 새 전투 계약 명세를 따르도록 확정했다. 강화 공격 시작에 별도 파동을 추가하는 것은 현재 범위에 포함하지 않는다.
- 극한 회피: 성공 확정 순간 한 번 발동한다. 단순 회피 시작에는 발동하지 않는다.
- 퍼펙트 패링과 극한 회피 모두 불릿 타임을 사용한다. 조건·배율·지속 시간·timeScale 쓰기는 A/D 소관이다.
- 중심: 퍼펙트 패링·극한 회피 모두 A의 PlayerRevealPulseEvent.Center(요청 당시 플레이어 위치)를 사용한다. 이후 중심은 고정된다.
- XZ 수평 거리로 공개하고 링은 지면에 배치한다.
- 파동이 도달한 일반 지형·적을 공개한다. 개별 인지 거리 밖 및 거리 0m인 적도 공개한다.
- 화면 밖 적은 동일 공개 결과로 방향 UI 표시 자격을 갖는다.
- 수리검은 이미 확정한 표시 규칙을 사용한다. 항상 보이는 배경은 기존 표현을 유지한다.
- 두 파동의 출발값: 최대 반경 12m, 확산 1.2초, 종료 페이드 0.6초, 링 흰색.
- 시작 반경 0.25m, 공간 경계 페이드 0.75m에서 시작하고 파동별 Inspector에서 조절한다. 공간 경계 페이드는 종료 시간 페이드와 별개다.
- 퍼펙트 패링·극한 회피 설정을 분리하고 반경·확산 시간·페이드 시간·색상을 Inspector에서 각각 조절한다.
- 파동 발동 시 설정값을 복사한다. 재생 중 설정 변경은 다음 파동부터 적용하며 현재 파동의 반경·시간·색상은 유지한다.
- 확산: 일시정지를 제외한 실제 시간. 도달한 원 내부는 공개 상태를 유지한다.
- 확산 완료 직후 추가 유지 시간 없이 게임 시간 기준 페이드를 시작한다.
- 페이드: 최대 반경을 유지하면서 공개 영역 전체와 링이 함께 흐려진다. 반경을 축소하지 않는다.
- 링·CPU 인지·셰이더 인지·지형 기억은 동일한 확산 상태를 사용한다.
- 여러 파동은 독립 유지하고 겹친 영역의 최대 가시성을 사용한다. 동일 요청 ID는 한 번만 처리한다.
- 기존 임시 인지 영역 상한 16개를 유지하고 초과하면 가장 오래된 영역을 교체한다.
- 지형은 기존 기억에 남기고 적의 위치·외형은 기억하지 않는다.
- 일시정지 시 확산·페이드·발소리 수명이 모두 정지한다.
- 게임오버·재도전 시 활성 파동·후보·중복 요청 기록을 정리한다.
