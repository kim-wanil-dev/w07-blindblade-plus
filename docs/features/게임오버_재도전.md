### 게임오버 재도전

- 2026-10-15 Stage1 보스 체크포인트: `GameStateManager.Restart`의 현재 씬 재로드는 그대로 사용한다. `BambooStage1Controller`가 보스전에 도달한 저장값을 읽어 재로드 시 일반 웨이브를 건너뛰고 중앙 플레이어 대 정면 공터 끝 보스로 시작한다. 체크포인트 기록·초기화는 [대숲 스테이지 1](대숲_스테이지1.md) 명세를 따른다. 실제 사망·버튼 클릭·재도전 Play 확인은 미실시다.

- 기능 설명: 게임오버 UI의 재도전 텍스트를 클릭하면 대각선 절단·발광·페이드 연출 후 현재 게임 씬을 재시작한다.
- 동작 조건 및 처리 흐름: GameOverUI.Initialize에서 GameStateManager 상태와 재도전 버튼을 연결한다. GameOver 상태에서 클릭하면 버튼 중복 입력을 막고 TMP 메시를 양쪽 조각으로 만든다. Time.unscaledDeltaTime으로 연출을 마친 뒤 기존 GameStateManager.Restart를 호출하여 상태·시간·커서를 복구하고 씬을 다시 로드한다.
- 구현 상태: 클릭 불가 설정 수정 및 절단 연출 구현, Unity 컴파일 오류·경고 0건. 실제 마우스 클릭·절단 외형 검증은 미확인이다.
- 2026-10-14 시간 소유권 연결: 정식 BambooDefense에서 `GameStateManager`는 직접 `Time.timeScale`을 저장·복원하지 않는다. `CombatSessionRuntime.SetFrozen`으로 게임오버 정지를 요청하고 재도전 전 해제하며, 살아 있는 슬로모션 요청은 같은 런타임이 다시 합성한다. 이번 변경은 Play 재도전을 실행하지 않았다.
- 2026-10-14 S6: 빌드의 `GameStateManager.Restart`는 `SceneManager.LoadScene(현재 씬 경로)`를 쓰므로 씬이 빌드 목록에서 활성이어야 한다. BambooDefense를 빌드 인덱스 1로 활성화한 뒤 Windows 개발 빌드에서 재도전 버튼 `onClick` 호출(API)로 게임오버 → 재도전을 2회 확인했다. 매번 새 Director·처치 0·생존 시간 0·시간 배율 1·커서 잠금으로 시작했다. Editor는 `LoadSceneInPlayMode`를 써서 재도전 뒤 buildIndex가 -1로 보이지만 빌드에서는 1이다.

#### 연결 및 협업

- 연결된 기능: UIManager의 GameUI 초기화, GameStateManager.StateChanged·Restart 및 기존 인트로 절단 셰이더를 사용한다.
- 공유하는 코드 및 상태: 절단 셰이더는 재사용하고 폰트·메시·머티리얼은 선택한 재도전 텍스트에서만 복제한다. UV0.xy와 UV0.w를 보존하고 조각을 원본 텍스트의 자식에 배치하여 UI 배칭 및 레이아웃의 좌표 변환에 영향받지 않도록 한다.
- 중복 또는 충돌 사항: 기존 GameStateManager와 IntroMenu 및 인트로 셰이더는 수정하지 않는다. 게임오버 전용 GameOverUI와 프리팹의 재도전 TMP 클릭 설정만 변경한다.
- 승인 필요 사항 및 결과: 사용자 요청에 따라 재도전 연출 및 재시작 불가 원인 수정을 수행했다. 추가 연결 없음. GameOverUI의 재도전 텍스트 절단 그룹에서 시간·각도·이동 거리·절단면 폭·색상을 조절할 수 있다.
- 원인: 프리팹 재도전 Button의 배경 Image는 비활성화됐고 자식 TMP의 Raycast Target도 꺼져 있어 버튼에 클릭을 전달할 Graphic이 없었다. 배경 Image를 켜지 않고 자식 TMP의 Raycast Target을 켜서 기존 텍스트 외형을 유지했다.
- 실패 처리 및 수명: TMP 또는 셰이더가 없거나 지원되지 않으면 오류를 보고하고 재시작 자체는 기존 경로로 실행한다. 연출 중 재선택을 막고 완료 시 텍스트 숨김을 유지하며 화면 비활성화·세션 종료 시 코루틴과 생성 리소스를 정리한다.
- 검증: Unity CLI recompile 결과 completed, compilationFailed=false, errors=0, warnings=0을 확인했다. 저장된 UIManager 프리팹과 씬에서 재도전 TMP·Button의 직접 오버라이드가 발견되지 않았다. 플레이 검증은 미실행이다. feature/fixui2 브랜치 규칙에 따라 Git CLI·커밋은 수행하지 않았다.

- 절단 속도 조절: 기본 연출 시간을 0.35초에서 0.2초로 단축했다. 인트로 씬에 저장된 시간도 0.2초로 적용했다. 저장값을 파일로 확인했으며 실제 화면 재검증은 미실행이다.

- 절단 타격감: 0.2초 동안 조각 이동에 초반이 빠르고 뒤로 갈수록 감속하는 곡선을 적용하고 거리 1.8배, 초반 15% 구간 최대 크기 1.18배, 최종 크기 0.65배 및 양쪽 반대 방향 12도 회전을 추가했다. 각 배율과 회전 각도는 인스펙터에서 조절하며 원본 메뉴의 배치와 후속 동작은 유지한다. Unity 컴파일 오류·경고 0건, 실제 화면 재검증은 미실행이다.
