#### 치명타 피해 문맥 보존 (2026-10-24)

#### 2026-10-24 피격 충돌체를 피격 캡슐로 교체

#### Inspector 설정과 동작

- 프리팹 위치는 Assets/Resources/Enemies다. EnemyHealth의 Die On Any Hit는 기본 true이며 모든 적 프리팹에서 켜 둔다. 일반 공격·발도 등 양수 피해가 실제 적중하면 피해량에 관계없이 HP 0으로 사망한다. Max Health 기본값 30은 초기 표시 및 옵션을 끈 다회 피격 모드에서 사용한다. Hit Collider는 기존 Placeholder Collider이며 새 Collider나 전역 Layer는 추가하지 않는다. Cancel Attack On Hit의 기본값은 false다.
- EnemyHealth가 직접 IDamageable을 구현하므로 같은 적 루트에 별도 DamageReceiver를 중복 추가하지 않는다. Damaged(DamageContext), HealthChanged(float current, float max), Died(EnemyHealth)는 C# 이벤트이며 Inspector 배열을 만들지 않는다. HP 0 시 사망 이벤트 후 적 루트를 비활성화하여 이동·공격·Collider를 종료한다. 다시 활성화하면 최대 HP로 초기화한다.
- EnemyCombatService의 Player Root는 메인 씬 플레이어다. Normal Damage 기본값은 10, Hit Radius는 0.2m다. Attack Mask는 모든 레이어를 포함하여 Ignore Raycast 레이어의 기존 적 Collider도 검출한다. 원점 겹침과 SphereCast로 가장 가까운 접촉을 고르고 자기 계층을 제외하며 벽이 먼저면 빗나감 결과를 반환한다.
- 일반 공격은 적 HP를 감소시키고 발도 요청은 실제 적중했을 때 남은 HP를 소진한다. PreferredTargetId가 있으면 그 적과 일치할 때만 피해를 적용하며 같은 ActionId는 마지막 결과를 반환하여 중복 피해를 방지한다. PlayerAttackResolution의 ActionId, HitConfirmed, HitTargetId, DeathConfirmed를 기존 플레이어에 반환한다.
- EnemyHealth.TargetId는 인스턴스의 고유 식별자다. 기존 IPlayerPerceptionProvider가 발도 자동 타겟을 제공하려면 이 ID로 PlayerPerceivedTarget을 전달해야 한다. 이번 작업은 청각 감지 대상을 임의 생성하지 않는다. 따라서 전투 판정 제공과 발도 자동 타겟 감지 연결 완료는 별개다.
- EnemyChargeHitbox는 같은 루트의 일반·박자 돌진 알림을 구독한다. 전조는 판정하지 않고 Active 이동 구간의 SphereCast와 양 끝 겹침을 검사한다. 네 박자 이동 중 같은 수신자에 한 번만 피해를 전달하며 쉼·후딜·취소 구간은 제외한다. 기본 피해 10, Radius 0.5m, Height 1m이며 지정 대상만 타격한다.
- 근접도 지정 대상 계층만 판정하여 HP가 생긴 다른 적을 우연히 타격하지 않는다. 원거리의 기존 투사체·콜백 구조는 유지한다. 플레이어는 기존 DamageReceiver로 공격 정보를 수신하며 실제 플레이어 HP·피격 가드·사망은 플레이어 담당자가 연결한다.

#### 메인 씬 보존 및 검증 한계

- 메인 씬의 기존 프리팹 인스턴스는 Unpack하거나 다시 생성하지 않는다. 저장 시 기존 미저장 씬 변경을 포함하여 유지했다. 플레이어의 Perception Provider Source, Map Service Source, 기존 임시 ActionDriver와 감각 매니저는 교체하지 않는다.
- 적 배치 메뉴의 이전 Assets/Prefabs/Enemies 경로를 현재 Resources 경로로 수정한다. 앞으로 메뉴 배치 및 프리팹 드래그에서도 HP와 해당 돌진 판정을 상속한다.
- Unity가 새 타입을 반영하고 메인 씬의 적 5개에 HP, 돌진 적 2개에 판정 컴포넌트가 연결된 것을 저장 결과에서 확인했다. 테스트 코드 작성 및 Play 실행은 하지 않았다. 실제 검 적중·HP 감소·사망·돌진 피해·감각 연출은 사용자 실행 확인 대상으로 남긴다.
- 편집 상태 확인 결과 메인 씬의 누락 스크립트는 0개, 적 5개의 Hit Collider 참조는 모두 연결됨, 01_World_NavMesh의 베이크 데이터는 유지됨이다. Combat Source는 새 서비스이며 기존 Perception·Map Source는 null 상태 그대로 유지했다. 모든 적의 한 대 사망 옵션은 원본 프리팹 4종에 저장한다.
