# 대숲 스테이지 1

## 현재 진행

BambooStage1은 빌드의 1막 정식 씬이다. BambooStage1Controller의 코드 기본 처치 목표는 5명이지만 현재 씬 저장값은 100명이며 실행 시 씬 값이 적용된다. 신규 진입 시 1막 제목을 잠시 표시한 뒤 일반 웨이브를 시작한다. 씬 저장값에서 시작 시 즉시 보스전은 꺼져 있고, 100명을 처치하면 웨이브를 끝내고 보스 경고를 표시한다. 보스 체크포인트가 저장되어 있으면 재진입 시 일반 웨이브를 건너뛰고 보스전으로 들어간다.

처치 목표를 달성하면 DefenseDirector가 스폰·투척을 중단하고 남은 근접 적과 투척수를 정리한다. 적대 비행 수리검도 해제한다. 정리는 처치로 기록되지 않는다. 2초 경고가 끝나면 공터 경계 안 NavMesh에서 플레이어와 경로가 연결된 가장 먼 지점에 보스를 배치한다. 등장 시 플레이어 체력을 최대로 회복하고, 붉은 등장 파동과 카메라 흔들림을 재생한다. 보스는 등장 파동이 끝난 뒤 전투를 시작한다.

보스 사망 시 3초 소멸 연출과 함께 1막 완료 상태가 되고, 같은 3초가 지난 뒤 완료 UI를 표시한다. 완료 UI에서 다음 막으로 진행하면 RainyTwinBoss를 연다.

## 씬에 저장된 스폰·처치 설정

| Inspector 값 | 현재 값 |
| --- | ---: |
| Required Kills | 100 (씬 저장값, 코드 기본값 5) |
| Melee Start Time | 웨이브 시작 즉시 |
| Melee Spawns Per Minute | 70회, 첫 1분 평균 목표 |
| Melee Spawn Multiplier Per Minute | 1.35 |
| Maximum Melee | 동시 생존 200명 |
| Melee Spawn Limit | 0, 누적 생성 제한 없음 |
| Minimum Spawn Distance | 13m |
| Melee Spawn Radius | 22.5~23.4m |
| Thrower Start Time | 웨이브 시작 즉시 |
| Initial Throwers | 1명 |
| Throwers Per Minute | 목표 동시 수 분당 2명 증가 |
| Maximum Throwers | 6명 |
| Thrower Spawn Interval | 1.33초 |
| Charge-type melee | 웨이브 경과 90초부터 생성 확률 40% |

근접 적은 DefenseMelee만 사용한다. 투척수 스폰 목표와 근접 적 스폰율은 서로 독립적이다. 근접 스폰율은 첫 1분 평균을 맞춘 지수 곡선을 사용하며 고정 100회/분 설정은 아니다. 스폰 규칙은 [대숲 방어](대숲_방어.md)를 따른다.

## 보스 및 클리어 연결

- 현재 씬은 시작 시 즉시 보스전 옵션을 끈 상태로 저장한다. 저장된 보스 체크포인트는 이 옵션과 별도로 재도전 시 웨이브를 건너뛰게 한다.
- 보스는 Boss_SoundDuel 프리팹을 사용하며 프리팹 최대 체력은 250이다.
- BossDeathDissolve의 연출 시간은 3초다. BambooStage1Controller가 이 시간 뒤 ActCompleteUI를 띄운다.
- GameStateManager는 1막 완료 상태에서 커서를 표시한다. 완료 카드의 진행 버튼이 RainyTwinBoss로 이동시킨다.
- 보스 패턴, 체력·피격 판정과 소멸 표현의 세부 명세는 [사운드 중심 보스전](사운드_중심_보스전.md), [적 피격 캡슐](적_피격_캡슐.md), [게임 클리어 화면](게임_클리어_화면.md)을 따른다.

## 확인 상태

씬 저장값, 프리팹 참조, 코드 흐름을 확인했다. Unity Play에서 현재 밸런스·연출·다음 막 이동은 이번 문서 갱신 과정에서 확인하지 않았다.
