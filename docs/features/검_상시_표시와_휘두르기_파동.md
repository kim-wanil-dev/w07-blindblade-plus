### 검 상시 표시와 휘두르기 파동

- 기능 설명: 플레이어 검(칼과 칼집)은 파동이 없어도 항상 최대 세기 윤곽선으로 보인다. 일반 공격이나 돌진 일섬으로 검을 휘두를 때마다 플레이어 발밑에서 파동이 한 번 퍼진다(2026-10-15 사용자 요청).
- 동작 조건 및 처리 흐름:
  - 검 상시 표시: Player 프리팹 루트의 `PlayerWeaponReveal`이 검 모델 Animator(`KatanaRig`, `KatanaWeaponVisual`과 같은 참조) 아래 모든 렌더러를 처리한다. 대상은 칼날·코등이·손잡이·칼집 등이고, 손 모델은 없다. 이 렌더러들에 `OutlineLayer.FORCED_REVEAL_MASK`(렌더링 레이어 비트 27)를 켠다. 머티리얼마다 MaterialPropertyBlock `_ForcedReveal`에 세기 `_strength`(1)와 파동 무시 1을 넣는다. 화면 윤곽선의 강제 공개 패스가 이를 마스크 g 채널로 기록하고, `PerceptionColor`는 g가 1이면 파동 가시성 대신 세기만 쓴다. 그래서 검의 깊이·노멀 경계는 항상 선으로 보인다. 머티리얼별 속성 블록은 기존 값을 먼저 읽고 넣으므로, `KatanaWeaponVisual`이 칼날 색을 바꾸는 속성 블록과 함께 쓰여도 서로 지우지 않는다. 컴포넌트가 꺼지면 비트를 끄고 세기를 0으로 되돌린다. 검이 숨겨지면(`_showWeapon` 끔) 렌더러가 꺼져 보이지 않는다.
  - 휘두르기 파동: Player 프리팹 루트의 `PlayerSwingRipple`은 일반 공격 시작(`AttackStarted`·`NormalAttack`)이나 돌진 일섬 시작(`SlashStarted`)을 받으면 파동을 예약한다. 그 행동의 공통 베기 구간 시작(`PlayerActionDriver.GetStrikeWindow`, 검기 이펙트와 같은 순간)에 플레이어 위치(발밑)에서 `PerceptionRevealMap.EmitRipple`로 파동을 한 번 낸다. 회당 한 번이라 기본 링은 1겹이다. 반경 14.4m·퍼짐 1.2초·잔상 1.2초는 플레이어 걸음 파동과 같다. 베기 구간 전에 다른 행동으로 바뀌면 내지 않는다. 걸음 파동과 같은 시야 맵을 쓰므로 바닥 링 그림과 대나무 공개도 걸음 파동과 같다.
- 구현 상태: 2026-10-15 구현. Roslyn(dotnet build)으로 게임·에디터 어셈블리 컴파일 오류 0을 확인했다. 기존 경고 2건(CS0649·CS0414)만 있다. 셰이더 수정과 GUID를 직접 작성한 프리팹 연결은 Unity 재가져오기 뒤에만 확인할 수 있다. Unity Play는 미확인이다.

#### 관련 코드

| 파일 경로 | 클래스 / 메서드 | 역할 |
| --- | --- | --- |
| Assets/Scripts/Player/PlayerWeaponReveal.cs | PlayerWeaponReveal / Awake, OnEnable, OnDisable, Apply | 검 렌더러에 강제 공개 비트와 파동 무시 세기 속성 블록 적용·해제 |
| Assets/Scripts/Player/PlayerSwingRipple.cs | PlayerSwingRipple / HandleAction, Update, Emit | 휘두를 때 베기 구간 시작에 발밑 파동 한 번 |
| Assets/Shaders/OutlineForcedReveal.shader | Frag | `_ForcedReveal.y`(파동 무시)를 마스크 g에 기록 |
| Assets/Shaders/ScreenSpaceOutline.shader | PerceptionColor | g가 1이면 파동 가시성 대신 세기만 사용 |

#### Inspector 설정

- Player 프리팹 → `Player Weapon Reveal`(루트): Weapon = 검 Animator(KatanaRig), Strength 1.
- Player 프리팹 → `Player Swing Ripple`(루트): Ripple Radius 14.4, Expand Duration 1.2, Ring Count 1, Ring Interval 0.15, Afterimage 1.2, Ring Color 흰색.

#### 연결 및 협업

- 연결된 기능: [화면 공간 윤곽선](화면_공간_윤곽선.md)의 강제 공개 마스크, [대나무 베기](대나무_베기.md)(같은 마스크를 g=0으로 사용), [감각 표현](감각_표현.md)의 걸음 파동 시야 맵, [카타나 전투 V2](카타나_전투_V2.md)의 베기 구간과 검 모델
- 공유하는 코드 및 상태: 렌더링 레이어 비트 27, `_ForcedReveal` 속성 블록, `PerceptionRevealMap` 파동 128개 한도, Player 프리팹
- 중복 또는 충돌 사항: 강제 공개 마스크에 대나무 베기 때 뺐던 파동 무시 채널(g)을 다시 넣었다. 대나무는 g=0이라 동작이 같다. `KatanaWeaponVisual`의 칼날 색 속성 블록과 같은 머티리얼 블록을 나눠 쓴다. 휘두르기 파동은 걸음 파동과 같은 일반 파동이라, 적 몸체도 밝힌다.
- 승인 필요 사항 및 결과: 2026-10-15 사용자 요청. 화면 윤곽선 셰이더 수정은 같은 날 대나무 베기에서 승인한 강제 공개 마스크의 확장이다. Player 프리팹은 HUD·통합 담당 소유라 변경을 알려야 한다.
- 미확인: Unity 재가져오기 뒤 스크립트 GUID 연결, 머티리얼별 속성 블록이 덮어쓴 재질 그리기에 전달되는지, 검이 어두운 곳에서 항상 윤곽선으로 보이는지와 너무 밝거나 화면을 가리지 않는지, 휘두를 때마다 파동이 한 번만 나는지(연계 2타·반격·돌진 일섬 포함), 파동 크기가 적절한지.
