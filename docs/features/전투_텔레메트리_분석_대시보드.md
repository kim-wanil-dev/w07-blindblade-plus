# 전투 텔레메트리 분석 대시보드

### 기능 이름

- 기능 설명: 온보딩, 일반 전투, 보스전 텔레메트리를 시각화해 플레이 의도와 플레이어 행동을 비교한다. 비공개 Sites URL은 `https://blindblade-combat-analysis.wan1k.chatgpt.site`다.
- 동작 조건 및 처리 흐름: 페이지 진입 시 Sites Worker가 서버에서 Apps Script 읽기 API로 POST 요청을 보내 Events·Sessions·OnboardingSteps의 분석 필드만 읽는다. 연결이 준비되지 않았을 때는 사용자가 Google Sheets 탭별 CSV 또는 `Export-Telemetry.ps1`로 생성한 CSV를 선택해 브라우저에서 분석할 수 있다.
- 구현 상태: 대시보드 Worker를 소유자 전용 Sites 버전 2로 배포했고, 2026-10-16에 기존 Apps Script 웹 앱 URL을 유지하면서 `dashboard_snapshot` 읽기 핸들러를 버전 6으로 배포했다. Apps Script 실행 계정과 `Anyone` 액세스 설정은 기존 값 그대로다. 자동 데이터 로드는 같은 `DASHBOARD_READ_TOKEN`을 Script Properties와 Sites 런타임 secret 양쪽에 설정하고 Sites 버전 2를 다시 배포해야 활성화된다. 토큰은 아직 생성·저장하지 않았다. 사이트와 스프레드시트는 비공개 상태다.

#### 연결 및 협업

- 연결된 기능: [전투 로그 및 Google Sheets 자동 전송](전투_로컬로그_자동전송.md)의 0-1·0-2·1-1·1-2 데이터와 CSV 전처리기.
- 공유하는 상태: 대시보드 상태는 페이지 메모리에만 둔다. CSV 행과 지표를 서버로 보내거나 브라우저 저장소에 기록하지 않는다.
- 중복 또는 충돌 사항: Events·Sessions·OnboardingSteps는 필수 권장 입력이다. Patterns·Heatmaps·Diagnostics를 추가로 올릴 수 있으며, 이미 제공된 Events로 같은 히트맵을 다시 계산할 수도 있다.
- 승인 필요 사항 및 결과: 자동 연결 코드와 서버 경로는 준비됐지만, Apps Script·Sites에 별도 `DASHBOARD_READ_TOKEN`을 영구 저장하는 외부 설정은 미완료다. 시트 공유는 비공개로 유지하고 기존 게임 업로드용 `UPLOAD_TOKEN`은 재사용하지 않는다.

#### 집계 규칙

- Sessions를 구간별로 묶어 도전 수·사망 수·평균 활성 플레이 시간을 표시한다. 사망률은 사망 수/도전 수다.
- 피해량은 rangedDamage, meleeDamage, bossRangedDamage, bossChargeDamage로 나눈다. 이는 적용된 피해량의 합이며 패턴별 피해량 비중은 별도 Patterns.csv를 통해 확인할 수 있다.
- 온보딩은 OnboardingSteps의 목표 행으로 활성 시간, 첫 입력, 행동 시도, 오입력, 이동 시도, 재도전, 종료 이유를 표시한다.
- Events의 enemy_attack_resolved에서 outcome별 적 공격 결과 및 적중률을 집계하고, reaction_seconds와 input_to_contact_seconds를 각각 평균·분포로 표시한다.
- Heatmaps.csv는 stage_attempt_id별 stage·layer·격자 좌표·가중치 합계다. 구간 필터는 직접 적용한다. 빌드·날짜·Editor 필터는 Heatmaps.csv 자체에 관련 열이 없으므로 Sessions를 함께 불러온 경우 해당 Sessions의 stage_attempt_id만 남긴다. Sessions가 없을 때는 필터를 정확히 적용할 수 있는 Events.csv에서 다시 계산한다.
- 원거리 공격 선은 Events의 origin_x/origin_z에서 x/z로 연결하며 실제 유도 궤적을 뜻하지 않는다.
- 스프레드시트 CSV를 불러올 때 각 탭을 개별 CSV로 저장한 뒤 한 번에 선택한다. 로컬 JSONL을 쓸 경우 README의 전처리 명령으로 CSV를 만든다.

#### 자동 연결 보안 구조

- 정적 페이지는 Google 로그인 세션이나 서비스 계정을 갖지 않는다. 시트 URL을 아는 것만으로 소유자 전용 데이터를 가져올 수 없다.
- 시트 공유를 링크 공개로 바꾸면 Sites 서버에 권한을 준 것이 아니라 데이터가 링크 보유자에게 공개된다. 이 프로젝트의 플레이 로그에는 권장하지 않는다.
- Apps Script `doPost`의 `dashboard_snapshot` 경로는 별도 `DASHBOARD_READ_TOKEN` Script Property를 검증하고 Events·Sessions·OnboardingSteps의 허용 열만 JSON으로 반환한다. 이 변경은 2026-10-16에 기존 URL의 웹 앱 버전 6으로 배포했다. 게임 전송의 `UPLOAD_TOKEN`과 분리한다.
- Sites Worker는 브라우저 요청의 Sites 사용자 인증을 확인한 뒤 서버에서 Apps Script URL로 POST하고, 키를 런타임 secret `DASHBOARD_READ_TOKEN`으로만 읽는다. 브라우저에는 키를 전달하지 않는다. Apps Script 웹 앱은 요청을 받을 수 있어야 하며, 읽기 핸들러가 별도 토큰을 반드시 검증해야 한다.
- 구현·배포 이후 검증할 것: 비로그인 또는 키 없는 요청 거부, 유효 토큰으로 필요한 탭만 읽기, 브라우저 번들·응답에 토큰 미노출, 과거 로그 누락·행 제한 여부.

#### 운영 및 확인

- 대시보드 소스: `tools/combat_telemetry/dashboard_site`.
- 데이터 원본: 현재 제공받은 Google Spreadsheet의 Events, Sessions, OnboardingSteps 탭과 선택 CSV.
- 사이트 접근은 소유자 전용으로 유지한다. 시트 행 사본을 사이트 소스나 빌드 산출물에 포함하지 않는다.
- 2026-10-16: Sites 버전 2 배포가 `succeeded`로 확인됐다. 배포 URL은 `https://blindblade-combat-analysis.wan1k.chatgpt.site`다. Worker ESM 생성·문법 검증을 통과했다. Apps Script 웹 앱 버전 6 배포도 확인했다. 두 위치의 `DASHBOARD_READ_TOKEN` 설정과 자동 데이터 로드는 아직 미완료다.
