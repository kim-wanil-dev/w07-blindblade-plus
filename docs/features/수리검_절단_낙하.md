### 수리검 절단과 낙하

- 기능 설명: 일섬·거합으로 제거되는 일반·보스 수리검이 현재 위치에서 두 조각으로 갈라지고, 중력으로 떨어져 바닥 접촉 시 사라진다.
- 동작 조건 및 처리 흐름:
  - 기존 일섬의 돌진·검기 경로와 거합 범위가 호출하는 `ReleaseBlocked`에서 절단 연출을 생성한다. 공격 범위와 피해량은 기존 값을 사용한다.
  - `ShurikenVisualRotation`이 붙은 모델의 읽기 가능한 메시를 중심 X 평면으로 자른다. 원본 UV·법선·재질·서브메시를 유지하고, 모델별 절반 메시 두 개를 캐시해 재사용한다. 일반 구형 투사체에는 적용하지 않는다.
  - 절단 당시 위치·크기를 유지하며 각 절반의 중심을 회전축으로 삼는다. 플레이어를 향해 윗면을 기울이는 비율을 조각마다 35~100%, 전환 시간을 0.06~0.28초로 정한다. 목표 자세에는 X/Z ±35도, Y ±180도의 무작위 각도를 추가한다. 전환 후에는 방향 편향 없는 무작위 회전축으로 초당 60~620도 회전하며 낙하한다.
  - 절단 순간 양쪽 조각을 수평으로 각각 3cm 벌린 뒤 조각마다 0.12~0.22초 동안 위치를 유지한다. 위쪽 초기 속도는 0이며, 정지 시간이 끝나면 중력으로 낙하한다. 위치 정지 중에도 윗면을 드러내는 회전 연출은 진행한다. 낙하 시작 프레임에는 정지 시간이 지난 부분만 적분해 갑자기 아래로 튀지 않게 한다.
  - 낙하 중 조각의 좌우 분리 방향에 수평 ±80도 편차를 주고, 수평 분리 속도는 0.385~2.64m/s에서 뽑는다. 같은 수리검의 두 조각에는 최대 1.2m/s의 공통 수평 드리프트를 더한다. 무작위 값은 생성 시에만 정하고 이후 중력으로 부드럽게 이동시킨다. 실제 Rigidbody는 추가하지 않으며 게임 일시정지·시간 배율은 `Time.deltaTime`을 따른다.
  - 조각에는 원본 공격 컴포넌트·비행음·위협 인디케이터·인지 공개 컴포넌트를 복제하지 않는다. 원본 수리검은 즉시 기존 종료 경로를 타고 제거되며, 조각은 빨간 Threat 실루엣을 유지한다.
  - 조각의 이동 구간을 반경 0.02m로 검사한다. 원본의 충돌 마스크를 사용하며 트리거·플레이어·적·수직 벽은 바닥으로 처리하지 않는다. 위를 향한 표면(법선 Y 0.5 이상)에 낙하 접촉하면 그 조각을 제거한다. 바닥이 없으면 8초 후 안전 정리한다.
  - 이미 종료되거나 반사된 일반 수리검에는 새 절단 연출을 생성하지 않는다. 일반 수명 종료와 지형·플레이어 충돌 소멸에는 이 연출을 추가하지 않는다.
- 구현 상태: 2026-10-24 구현 완료. Unity 재컴파일 오류 0건·경고 0건. 일반·보스 수리검 프리팹이 읽기 가능한 동일 `Shuriken3.FBX` 메시와 회전 컴포넌트를 사용하는 것을 확인했다. 실제 Play 화면에서 절단·낙하·바닥 소멸 연출은 미확인이다. 테스트 코드는 추가하지 않았다.

- 2026-10-24 낙하 다양화: 수리검별 수평 드리프트와 조각별 분리 방향·속도·상승 높이·목표 자세·회전축·회전 속도를 무작위로 정한다. 처음 0.12초의 윗면 공개 이후에 회전을 시작하여 절단 모양이 먼저 드러나도록 했다. 빨간 실루엣·바닥 접촉 제거·수명 정리와 공격 종료 처리는 유지한다. Unity 재컴파일 오류 0건·경고 0건. 실제 플레이 화면에서 다수 수리검 낙하의 자연스러움은 미확인이다.
- 2026-10-24 무작위 편차 확대: 분리 방향 ±35→±80도, 드리프트 최대 0.45→1.2m/s, 회전 속도 100~280→60~620도/초로 확대했다. 윗면을 향하는 고정 비율 85%·시간 0.12초도 조각별 35~100%·0.06~0.28초로 변경하고 추가 기울기 범위를 확대했다. 이 항목과 위 동작 조건이 앞선 고정값 기록보다 우선한다. 실제 플레이 화면은 미확인이다.
- 2026-10-24 상승 제거: 위로 솟는 초기 속도를 없애고, 수평으로 갈라져 0.12~0.22초간 위치를 유지한 뒤 낙하하도록 변경했다. 이 항목과 현재 동작 조건이 앞선 상승 높이 기록보다 우선한다. 실제 플레이 연출은 미확인이다.

#### 연결 및 협업

- 연결된 기능: 일섬 돌진·검기, 거합 범위 판정, 수리검 비행 종료와 Guard 효과음, 화면 공간 윤곽선.
- 공유하는 코드 및 상태: 원본 수리검의 충돌 마스크와 모델 재질, `OutlineLayer.THREAT_MASK`를 사용한다. 절단 캐시는 새 Play 시작 시 해제한다.
- 중복 또는 충돌 사항: 기존 즉시 소멸하던 `ReleaseBlocked` 경로에 외형 연출만 추가한다. 비행 종료·발사자 통지·공격 로그는 기존 경로에서 처리한다.
- 승인 필요 사항 및 결과: 사용자가 일섬·거합의 수리검 제거 연출 변경을 요청했다.
