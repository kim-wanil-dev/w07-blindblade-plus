- 중복 또는 충돌 사항: 공통 Managers와 SoundManager 코드는 수정하지 않는다. 기존 IntroMenu의 미구현 기능을 사용자 요청 범위 안에서 완성한다.
- 승인 필요 사항 및 결과: 과거에는 SampleScene을 목적 씬으로 사용했다. SampleScene 파일이 현재 없어 실제 시작 대상과 빌드 등록을 다시 정해야 한다.

- 설정 팝업의 슬라이더는 기준 해상도 1920×1080에서 중앙 아래 260, 크기 420×32, 배율 1로 배치되어 있다. 실제 화면·음량 조작 검증은 미실행이다.

- 연결 오류 수정: 열린 IntroScene에서 VolumeControlUI의 세 참조 누락을 확인하여 볼륨 버튼·패널·슬라이더를 직접 연결하고 씬을 저장했다. Unity SerializedObject 조회로 세 참조와 저장 상태를 확인했으며 플레이 검증은 미실행이다.

- 음량 패널 스타일: 중앙 아래 360 위치의 RectTransform 컨테이너에 520×180 어두운 카드, 얇은 금색 테두리, 전체 음량 제목과 작게/크게 라벨을 배치하고 슬라이더를 금색으로 정리했다. Play Mode에서 볼륨 버튼의 패널 표시를 확인하고, 촬영 시에만 카메라 캔버스로 전환하여 시각 확인 후 원래 Overlay 모드로 복원했다.

- 텍스트·이미지 절단 연출: 시작·종료·설정 버튼 입력 시 TMP 메시와 이미지 메시를 복제해 양쪽 조각을 이동하고 절단면 발광을 표시한다. 절단 조각 생성은 `IntroBambooButtonSliceEffect`가 담당하고, 호버·키보드 선택만으로는 재생하지 않는다. 클릭 시 StreamingAssets의 `UI/BambooButtonCut.mp3`를 `Managers.Sound.PlayStreamingEffect`로 재생한다.
- 조절 및 연결: 절단 시간, 각도, 이동 거리, 발광 폭·색, 조각 이동·확대·회전, 사운드 파일 경로·음량·피치는 각 버튼의 `IntroBambooButtonSliceEffect` Inspector에서 조정한다. 버튼 사운드 파일은 `Assets/StreamingAssets/UI/BambooButtonCut.mp3`에서 교체하며, `SoundManager`가 FMOD Core 스트림으로 SFX_Bus에 연결해 효과음 옵션 음량을 적용한다. 셰이더는 `Resources/Effects/IntroTextSlice`와 `Resources/Effects/IntroBambooImageSlice`를 사용한다.
- 수명: 절단 완료 또는 버튼 비활성화 때 임시 오브젝트·메시·머티리얼을 해제한다. 메뉴 버튼은 설정 팝업을 닫을 때 원본 이미지와 라벨을 복원하며, 설정 닫기 버튼은 팝업 재개방 전에 복원한다.

- 검증: 기존 씬의 시작·종료 버튼 TMP 구성, 셰이더 프로퍼티와 C# 설정 이름, 리소스 경로 및 정리 흐름을 파일에서 확인했다. Unity 컴파일·셰이더 컴파일·실제 화면은 미확인이다. 기존 SampleScene 대상 오류는 이번 작업에서 변경하지 않았다. 현재 dev 브랜치이므로 Git CLI 및 커밋은 수행하지 않았다.

- 절단 선택 범위 수정: 조각을 선택한 TMP의 자식으로 배치하여 메뉴 레이아웃 그룹에 새 항목이 추가되지 않도록 변경했다. 선택하지 않은 버튼의 배치는 유지하며 선택한 텍스트의 로컬 좌표에서만 절단·이동한다. 기존 MenuButtons의 레이아웃과 부모 구조를 파일에서 확인했으며 Unity 플레이 재검증은 미실행이다.

- 절단 좌표 수정: 선택한 TMP 메시 UV0.z에 로컬 절단선까지의 부호 있는 거리를 저장하고 픽셀 셰이더에서 양쪽 절반을 clip한다. UI 배칭으로 변환되는 정점 좌표와 로컬 중심을 직접 비교하지 않으며, 조각 이동은 텍스트 자식의 로컬 위치로 처리한다. TMP UV0.xy의 아틀라스 좌표와 UV0.w의 SDF 배율은 유지한다. 설치된 TMP 소스의 Vector4 UV0 사용을 확인했으며 Unity 컴파일·실제 화면은 미확인이다.

- 음량 모달: VolumeControlUI.CreateModal이 기존 패널 컨테이너를 실행 시 생성한 전체 화면 검은 Image 안에 배치하고 우측 상단에 닫기 버튼을 생성한다. 기존 씬·프리팹 직렬화 참조와 음량 슬라이더 설정을 유지하며 추가 수동 연결은 없다. 배경 Image가 포인터 입력을 차단하고 모달이 열린 동안 메인 메뉴 버튼의 interactable을 해제하여 키보드 선택도 차단한다.
- 음량 연동: `VolumeControlUI.OpenRequested` 이벤트를 `IntroMenu.BeginSlice`가 구독하여 설정 버튼 절단 후 팝업을 연다. 닫기 완료 시 `PanelClosed` 이벤트를 발생시켜 `IntroMenu.RestoreMenuTexts`에서 메뉴 버튼 이미지와 라벨을 복원한다. 이벤트 구독·해제는 `OnEnable`/`OnDisable`에서 대응한다.
- 절단 유지: 메뉴 버튼은 절단 완료 뒤 원본을 숨겨 두고 설정 팝업을 닫을 때 이미지와 라벨을 복원한다. 설정 닫기 버튼은 팝업이 다시 열릴 때 이미지와 라벨을 복원한다.
- 검증: 기존 씬에서 VolumeControlUI와 IntroMenu가 같은 Canvas에 있고 음량 패널 컨테이너 및 메뉴 버튼 부모 구성을 파일로 확인했다. 이벤트 시그니처·구독 해제·복원 호출 경로를 검토했으며 Unity 컴파일·실제 화면은 미확인이다.

- 절단 속도 조절: 기본 연출 시간을 0.35초에서 0.2초로 단축했다. 2026-10-17에 연출 설정을 `IntroBambooButtonSliceEffect`로 옮기고 기본값을 0.2초로 유지했다.
