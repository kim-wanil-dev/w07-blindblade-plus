### 위협 표시 판정

- 기능 설명: C 담당의 위협 표시 계산과 대상별 월드 렌더링이다. 거리·적 유형·개체별 거리·카메라 외형 교차·소유권·통과 상태로 월드와 UI가 공유할 결과를 계산한다.
- 동작 조건 및 처리 흐름: 대상이 Resolver에 등록되면 LateUpdate에서 거리·인지 반경·가시성·화면 분류·색상·방향을 불변 스냅샷으로 제공한다. 연결된 게임 카메라는 기본 표시를 잠깐 대체하고 개별 위협 캡처를 합성한 뒤 원본을 복원한다. Collider·공격·루트 활성 상태는 변경하지 않는다.
- 구현 상태: 첫 단위와 두 번째 단위는 사용자 커밋 완료다. D 공통 계약 v0.2.0에 C 결과를 연결하는 세 번째 단위를 구현했고 C 전용 씬의 사용자 실행 확인을 마쳐 커밋 인계 시점이다. 발소리 정책 변경·보상 파동·실제 B 프리팹과 정식 씬의 연결은 이후 작업이다. 검증 범위는 마지막 절을 따른다.

#### 확정 동작

- 거리 기준은 플레이어 루트 ↔ 대상 루트의 XZ 수평 거리다. 카메라 높이나 적 애니메이션으로 거리 기준이 바뀌지 않는다.
- 근접 적 기본 반경은 12m이며 마지막 1m에서 SmoothStep으로 페이드한다. 0m는 평상시 인지 없음이다. 페이드 폭은 반경 이하로 제한한다.
- 우선순위는 개체별 지정 → 유형별 지정 → 공통이다. 개체 안에서는 B가 전달한 런타임 지정이 Inspector 지정보다 우선한다. 런타임 지정을 해제하면 Inspector·유형·공통으로 복귀한다.
- 일반형·돌진형의 유형별 덮어쓰기는 기본적으로 꺼져 있다. 같은 프리팹도 B가 유형을 전달하면 다른 거리를 적용할 수 있다.
- 적대 수리검은 거리 제한이 없고 반사체는 기본 흰색이다. 반사체와 플레이어 통과가 확정된 수리검은 방향 UI에서 제외한다.
- 색상은 인지 반경과 별도로 공통 3~12m 기준이다. 3m 이하 RGB(1, 0.1, 0.06), 12m 이상 흰색이며 근접도 곡선으로 보간한다.
- 자격이 있는 대상은 안정된 화면 분류에 따라 ShowWorld 또는 ShowUi 중 하나만 참이다. 출력은 표시 요청이며 게임 카메라의 렌더링 경로가 ShowWorld를 소비한다.
- 화면 판정은 연결된 Renderer들의 월드 AABB 합집합을 사용한다. 외형 일부가 들어오는 것을 근사하며 실제 픽셀·정밀 메시 차폐는 검사하지 않는다. SkinnedMeshRenderer의 과도한 Bounds는 판정 오차를 만들 수 있어 연결할 외형을 제한해야 한다.
- 화면에 들어올 때는 실제 프러스텀, 나갈 때는 폭·높이 2%만큼 확장한 프러스텀을 사용한다. 여유 구간에서는 잠시 UI를 숨겨 전환 반복을 줄인다.
- 장면 벽·대나무 차폐는 검사하지 않는다. 두 번째 단위는 전용 깊이 버퍼로 위협끼리 가까운 표면을 앞에 그린다.
- Play 중 설정·개체 Inspector 변경은 다음 LateUpdate에 반영한다. 별도의 판정 지연은 없다.

#### 연결 및 협업

- 연결된 기능: [화면 공간 윤곽선](화면_공간_윤곽선.md), [대숲 방어](대숲_방어.md), [전투 판정 계약](전투_판정_계약.md).
- 공유하는 코드 및 상태: 신규 타입은 모두 BlindBlade.Perception 이름공간에 둔다. 전역 static 이벤트·등록 목록은 추가하지 않는다. Resolver 인스턴스가 한 세션의 표시 목록을 소유한다.
- 중복 또는 충돌 사항: 첫 두 단위는 C 임시 형식으로 진행했다. 이후 D 공통 계약 v0.2.0과 기존 공급자와의 중복을 비교했고, 사용자가 C 표시 규칙으로 연결하도록 승인했다. D 공급자 연결부와 월드 표시로 전환할 때의 HUD 종료 동작을 수정한다. B의 공식 표시 입력은 아직 연결되지 않았다.
- 승인 필요 사항 및 결과: 2026-10-14 사용자가 기존 표시 변경안을 승인했고, 이후 B/D 계약을 임시로 정의하여 필드·연결 명세와 함께 첫 단위를 구현하도록 지시했다. Git CLI·실제 커밋은 금지다.
- FEATURE_SPEC에는 이 기능의 목록 링크만 추가한다. 다른 담당자의 기존 계약·상위 기능 동작은 변경하지 않는다.

#### B → C 임시 입력 계약 v1

공식 계약 파일을 선점하지 않으며 **ThreatSourceState**가 임시 연결 경계다. B의 공식 데이터가 생기면 어댑터에서 이 구조체로 변환한다.

공통 계약 연결 단위부터 원본 문자열 식별자를 보존할 EntityId를 추가했다. 기존 생성자는 마지막 선택 인자를 생략해 그대로 사용할 수 있다.

| 필드 | 타입 | 의미·채우는 쪽 |
| --- | --- | --- |
| TargetId | int | B의 대상 식별자. 같은 세션의 활성 대상끼리 고유해야 한다. 공격 ID와 구분 |
| EntityId | string | 공통 계약의 원본 문자열 ID. 선택 인자 entityId로 전달하며 int로 해시하지 않음 |
| SpawnGeneration | int | 같은 대상 오브젝트의 새 생명마다 증가. B의 재사용 세대와 매핑 |
| Kind | ThreatTargetKind | 적은 Melee, 수리검은 Projectile |
| MeleeType | MeleeThreatType | 적 생성 시 B가 확정한 Normal 또는 Charge. 공격 종류로 임의 추정하지 않음 |
| Ownership | ThreatOwnership | 적대 Hostile 또는 플레이어 반사 Reflected |
| HasPassedPlayer | bool | B의 물리 통과 확정. 같은 식별자·세대에서는 한 번 true가 되면 되돌리지 않음 |
| IsActive | bool | 해당 생명이 표시 대상인지. 사망·제거를 false로 전달 가능 |

- 위치는 Target을 붙인 대상 루트 Transform에서 읽는다. 공식 위치 스냅샷을 사용하게 바뀌면 어댑터·계산 입력을 함께 맞춘다.
- 공급자가 없는 전용 씬에서는 GetInstanceID와 OnEnable마다 증가하는 로컬 세대를 사용한다. 편집 모드 미리보기 세대는 0일 수 있다. 이 ID는 영구 로그나 공식 B 식별자가 아니다.
- 공식 문자열/GUID는 EntityId에 원문으로 저장한다. TargetId는 C의 로컬 구분용 int로 유지할 수 있으며 문자열을 int로 해시하지 않는다. EnemyHealth.TargetId 또는 Projectile_ + ProjectileId를 실제 B 연결 시 공급한다.
- 호출 순서: 활성화 및 Register → ApplySourceState → 필요하면 SetRuntimeRadius → C LateUpdate → D 읽기.
- OnEnable은 기존 외부 상태·임시 거리를 초기화한다. 풀에서 재사용할 때 B는 활성화 후 새 상태를 전달한다.
- 새 ID·세대의 ApplySourceState도 이전 런타임 거리·화면 이력을 지운다. Inspector 기본값은 유지한다.
- 같은 생명의 상태 변경은 ApplySourceState로 전달한다. 비활성화 시 Target이 등록을 해제하며 D 목록에서도 제거된다.
- 공급자가 붙은 뒤 Inspector 임시 종류·소유권·통과 필드는 외부 상태를 덮어쓰지 않는다. 개별 거리 Inspector 설정은 계속 사용할 수 있다.

#### C 내부 렌더링·진단 결과 (기존 임시 출력 v1)

공통 계약 연결 후 D 외부 소비자는 다음 절의 BlindBlade.Combat.Contracts 타입을 사용한다. 이 내부 타입에는 거리·설정 출처·실제 화면 교차 등 C 진단 정보를 유지한다.

Resolver.Snapshots 또는 Target.Snapshot을 읽는다. Snapshots 목록은 매 LateUpdate 교체되는 읽기 전용 뷰이므로 프레임 밖에 보관하려면 각 구조체를 복사한다.

| 필드 | 타입 | 의미·사용 방법 |
| --- | --- | --- |
| TargetId, SpawnGeneration | int | 입력 식별자 그대로 전파. 마커 연결 키이며 세션 종료 때 D의 키 목록도 초기화 |
| EntityId, IsActive | string, bool | 입력의 원본 문자열 ID와 생명 활성 상태. 공통 어댑터가 사용 |
| Kind | ThreatTargetKind | 대상 종류 |
| Position | Vector3 | 계산 프레임의 대상 루트 월드 위치 |
| HorizontalDistance | float | 관측자 루트와 수평 거리(m) |
| EnemyRadius | float | 최종 근접 적 반경(m). 투사체는 해당 없음으로 0 |
| RadiusSource | ThreatRadiusSource | Default, Type, Individual, Runtime |
| IsEligible | bool | 활성 생명·유효 외형·거리 가시성이 있는지 |
| IntersectsCamera | bool | 실제 카메라 프러스텀과 외형 Bounds 교차 |
| IsInCamera | bool | 전환 여유를 적용한 안정된 화면 분류 |
| ShowWorld | bool | 실제 월드 표현 요청. 첫 단위에서는 렌더러를 직접 바꾸지 않음 |
| ShowUi | bool | 방향 UI 표시 요청. 반사체·통과 수리검 제외 완료 |
| DirectionDegrees | float | 카메라 수평 전방 기준 각도. 정면 0, 오른쪽 +90, 왼쪽 -90. 기존 원형 UI의 Z 회전에는 부호를 반대로 적용 |
| Color | Color | 공통 거리 색상 또는 반사체 색상 |
| Alpha | float | 거리 인지 가시성. 최종 알파는 Color.a와 Alpha를 한 번씩 곱해 적용 |

- D는 ShowUi·Color·Alpha·DirectionDegrees를 소비하고 거리·화면·통과 규칙을 재판정하지 않는다.
- C의 Resolver는 DefaultExecutionOrder(-20)의 LateUpdate에서 계산한다. D는 그 이후 LateUpdate에서 읽거나 명시적인 계산 이후 읽는다.
- 두 번째 단위의 게임 카메라는 이 스냅샷의 Color·Alpha·ShowWorld와 Settings.FillOpacity를 그대로 사용한다. 판정용 거리 계산을 셰이더에서 다시 하지 않는다.
- 표시 갱신은 전투 사실 사건이나 로그 원본이 아니다. 매 프레임 계산을 패링·처치 사건으로 기록하지 않는다.

##### 실제 B/D 연결 시 인계

- 정식 씬·B 프리팹은 이번 단위에서 직접 저장하거나 재생성하지 않았다. 위 메뉴는 C 전용 씬에서만 동작한다.
- 실제 DefenseDirector의 D 공급자에 위 C 어댑터를 연결하고, Resolver에 플레이어 루트·실제 카메라·C Settings를 연결한다. 실제 GameSceneInitializer의 CombatSessionRuntime을 어댑터에 연결한다.
- B가 대상 프리팹의 ThreatPresentationTarget에 Resolver·모델 Renderers를 연결하고 활성화 이후 ApplySourceState로 종류·유형·소유권·통과·활성·세대·원본 EntityId를 제공한다. 이 공급자 없이 슬롯만 연결하면 해당 실제 대상은 C 목록에 들어오지 않는다.
- 실제 ShurikenPerceptionEffect는 기존 감각 기준으로 Renderer.enabled를 바꾸므로 C 외곽선 경로와의 실제 연결 전에 담당자와 표시 소유권을 정리해야 한다. 이번 공통 DTO 연결 완료를 정식 게임 전체 통합 완료로 간주하지 않는다.
- 발소리 정책은 여전히 기존 2초 실시간 수명이다. 최신 후보 하나·0.8초 게임 시간·20m 등의 확정 C 계획은 이후 발소리 단위에서 교체한다.
