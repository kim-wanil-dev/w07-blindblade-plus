### 특수 스킬과 독립 게이지

- 기능 설명: 일섬은 소수 단위 3칸 자원을 소비하고 거합은 독립된 100% 자원을 소비한다. 두 스킬은 집중 여부와 무관하게 전용 키로 요청한다.
- 동작 조건 및 처리 흐름:
  - 패링: 일섬 +1칸, 거합 최대량의 정확히 1/3. 극한회피: +0.5칸/+15%p. 플레이어 처치: +0.1칸/+1%p. 보스 일반 공격 유효 적중: 거합만 +3%p.
  - 게이지 상한에서 초과분을 버린다. 자원은 새 플레이어에서 0이며 같은 인스턴스의 일반전→보스전에서는 유지한다.
  - Shift/패드 RT: 자유 상태에서 일섬 1칸 이상일 때 예약 없이 시전하고 1칸 소비한다. 첫 0.2초만 집중하며 돌진·검기는 기존 순서를 따른다. 종료·사망에서 시간 요청/FOV를 해제한다.
  - Q/패드 Y: 자유 상태에서 거합 100%일 때 0.75초 자동 차징한다. 버튼을 놓아도 계속하며 실제 거합 시작 때 거합만 전부 소비한다. 차징 취소 시 소비하지 않는다. 차징 중 이동·전투 입력을 잠그고 일시정지에서는 타이머를 정지한다.
  - 일반 공격 중 스킬 캔슬을 추가하지 않는다. 동시에 Q/Shift를 누르면 Q 요청을 우선 처리한다. 수락되지 않은 스킬을 일반 공격으로 변환하지 않는다.
  - 패링 성공 집중과 극한회피 집중, 성공 파동/무적은 유지한다. 집중 시간은 2026-10-23 Player.prefab에서 둘 다 3초로 바꿨다(이전 패링 5초·극한회피 1초, `PlayerEmpower._dodgeReadyDuration` 허용 범위 0.5~5초). 좌클릭은 정식 전투에서 일반 공격을 요청한다.
  - 보스 일반 공격 보상은 실제 피해 수락에서만 지급한다. 좌클릭 일반/대상 돌진 연계가 대상이며 일섬의 일반 베기 동작·검기·거합·반격·막힌 피해는 제외한다. 공유 체력 묶음의 같은 ActionId는 한 번만 적립한다. 보스 막타에서는 적중과 처치 보상을 합산한다.
  - 처치는 EnemyHealth의 직접 피해 사망에서 한 번 보상하며 공유 체력 동기화 사망/단순 비활성화에서는 추가 보상하지 않는다. 풀에서 재등장한 적은 새 처치다.
  - 쌍둥이 보스의 자동 역거합은 자원 소비 없이 기존 counter 출처를 유지한다. 수동 거합 차징 단축이 자동 반격의 기본 집중 시간 1.5초를 바꾸지 않는다.
- 구현 상태: 2026-10-23 M1 독립 자원 모델과 M2 입력·전투·보상 연결이 완료됐다. Unity 재컴파일 오류 0. Play 평가에서 Shift 일섬 소비와 약 0.21초 집중, Q 거합 자동 차징·일시정지 정지/재개·시전 시 1회 소비, 자원 부족 및 연타 거부, 좌클릭 일반 공격, 비활성화 및 사망 콜백의 시간 요청 해제를 확인했다. 차징 중 사망 콜백 평가에서는 거합 게이지 100%가 유지됐다. 실제 키 장치 입력은 Editor 포커스 문제로 확인하지 못했으며 실제 치명타 발생 통합도 미검증이다. #### 연결 및 협업

- 사용자 승인: 리메이크 계획 실행, luna-max 구현·어려운 통합은 sol 조정자가 직접 수행. 최신 조건은 패링당 정확히 1/3, 보스 일반 공격당 거합 3%p다.
- 온보딩 전용 코드·씬·문구·명세는 이번 변경 대상에서 제외했다. 공용 API는 남겨 컴파일 참조를 보존하며, 기존 온보딩의 홀드/정수 토큰 가정에 대한 새 규칙 적용과 완료 가능성은 후속 작업이다.
- 현재 브랜치는 feature/skill이며 Git CLI·커밋·푸시는 수행하지 않는다. Sites/Apps Script 배포는 포함하지 않는다.
- 이전 토큰·홀드 규칙의 날짜별 기능명세는 과거 기록이며 정식 전투의 현재 규칙은 이 문서를 우선한다.
- 2026-10-23 불릿 타임 발도(feature/bullet-time-dash-attack 병합): 패링·극한회피 집중 중 실이 연결된 적이 있으면 좌클릭은 일반 공격 대신 발도 돌진을 요청한다. 돌진 거리 절반까지 집중의 불릿 타임을 유지한 뒤 집중을 끝내며 게이지는 바꾸지 않는다. 돌진 중 일반 공격 부채꼴 휩쓸기 피해도 `Normal` 문맥이라 보스 적중 보상 대상이다. 일섬 집중·거합 자동 차징 중에는 발도를 허용하지 않는다. 도착 베기(`IaidoFinisher`)의 보스 적중은 기존 규칙대로 거합 +3%p 대상이다. 상세는 [1인칭 근접 교전](1인칭_근접_교전.md)의 2026-10-23 절을 따른다.
