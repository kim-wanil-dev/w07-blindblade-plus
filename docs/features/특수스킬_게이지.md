### 특수 스킬과 독립 게이지

- 기능 설명: 일섬은 소수 단위 3칸 자원을 소비하고 거합은 독립된 100% 자원을 소비한다. 두 스킬은 집중 여부와 무관하게 전용 키로 요청한다.
- 동작 조건 및 처리 흐름:
  - 패링: 일섬 +1칸, 거합 최대량의 정확히 1/3. 극한회피: +0.5칸/+15%p. 플레이어 처치: +0.1칸/+1%p. 보스 일반 공격 유효 적중: 거합만 +3%p.
  - 게이지 상한에서 초과분을 버린다. 자원은 새 플레이어에서 0이며 같은 인스턴스의 일반전→보스전에서는 유지한다.
  - Shift/패드 RT: 자유 상태에서 일섬 1칸 이상일 때 예약 없이 시전하고 1칸 소비한다. 돌진·검기는 기존 순서를 따르며 종료·사망에서 시간 요청/FOV를 해제한다. 일섬 집중 연출은 아래 2026-10-23 조정을 따른다.
  - 2026-10-23 가드·쳐내기 중 사용: Shift·Q는 게이지 조건을 통과하면 `KatanaCombatCoordinator.PrepareManualSkill`이 가드와 퍼펙트 패링 모션을 끝내고, 이어지는 납도는 기다리지 않고 칼집에 넣은 상태로 확정한 뒤 시작한다. 그래서 가드 중·쳐내기 모션 중·납도 중에도 쓸 수 있다. 공격·회복 중에는 여전히 쓸 수 없고, 게이지가 모자라 거부되면 모션을 끊지 않는다.
  - 2026-10-23 일섬 집중 조정(Player.prefab 값): 누르면 세계 0.1배(`PlayerEmpower._swordWaveFocusTimeScale`)·플레이어 0.5배(`_swordWaveFocusPlayerTimeScale`, `PlayerClock`이 적용)로 느려진다. `PlayerSwordWaveLauncher._dashStartDelay` 0.08 실시간 초 동안 제자리에서 기다린 뒤 돌진한다. 돌진이 거리 1/4(`_swordWaveFocusDashRatio` 0.25, `DashProgress`·`PlayerMotor.CombatPushProgress`)을 지나거나 끝나면 집중을 풀고 남은 돌진은 평소 속도다. `_swordWaveFocusDuration` 1.5초는 상한으로만 쓴다. 계산상 대기 0.08초, 감속 돌진 약 0.08초, 나머지 약 0.26초다.
  - 2026-10-23 일섬 집중 연출: 준비 비네트(`PlayerPerfectPulse.UpdateReadyVignette`, `EmpowerOverlay.SetVignette(target, blendTime)`), FOV 30°(`PlayerSwordWaveLauncher.UpdateFocusFov`), 불릿 타임 소리(`PlayerBulletTimeAudio`)가 모두 `PlayerEmpower._swordWaveFocusFadeIn` 0.04초에 들어오고 `_swordWaveFocusFadeOut` 0.06초에 빠진다. 소리는 일반 불릿 타임 세기의 15%(`_swordWaveWarpStrength`, 음높이 약 0.94배·약 13kHz 저역 통과)만 건다. 쳐내기·극한 회피 집중의 비네트·소리는 기존 전환 시간과 세기다. 레거시 온보딩의 좌클릭 일섬은 기존 돌진 곡선 FOV를 쓴다.
  - 2026-10-23 일섬 타격 정지: 일섬 돌진 몸 판정이 적을 새로 벨 때마다 세계·플레이어를 0.02배(`PlayerSwordWaveLauncher._hitStopTimeScale`)로 `_hitStopDuration` 0.02 실시간 초 멈춘다. 불릿 타임(일섬 집중 포함) 중에는 기본 시간을 세계 배율로 나눠 늘리되 `_hitStopBulletTimeMaxDuration` 0.03초를 넘기지 않는다. 정지 중 새 타격은 남은 시간을 늘리지 않고 소리는 바꾸지 않는다. 일반 공격에는 걸지 않는다.
  - Q/패드 Y: 자유 상태에서 거합 100%일 때 0.75초 자동 차징한다. 버튼을 놓아도 계속하며 실제 거합 시작 때 거합만 전부 소비한다. 차징 취소 시 소비하지 않는다. 차징 중 이동·전투 입력을 잠그고 일시정지에서는 타이머를 정지한다.
  - 일반 공격 중 스킬 캔슬을 추가하지 않는다. 동시에 Q/Shift를 누르면 Q 요청을 우선 처리한다. 수락되지 않은 스킬을 일반 공격으로 변환하지 않는다.
  - 패링 성공 집중과 극한회피 집중, 성공 파동/무적은 유지한다. 집중 시간은 2026-10-23 Player.prefab에서 둘 다 3초로 바꿨다(이전 패링 5초·극한회피 1초, `PlayerEmpower._dodgeReadyDuration` 허용 범위 0.5~5초). 좌클릭은 정식 전투에서 일반 공격을 요청한다.
  - 보스 일반 공격 보상은 실제 피해 수락에서만 지급한다. 좌클릭 일반/대상 돌진 연계가 대상이며 일섬의 일반 베기 동작·검기·거합·반격·막힌 피해는 제외한다. 공유 체력 묶음의 같은 ActionId는 한 번만 적립한다. 보스 막타에서는 적중과 처치 보상을 합산한다.
  - 처치는 EnemyHealth의 직접 피해 사망에서 한 번 보상하며 공유 체력 동기화 사망/단순 비활성화에서는 추가 보상하지 않는다. 풀에서 재등장한 적은 새 처치다.
  - 쌍둥이 보스의 자동 역거합은 자원 소비 없이 기존 counter 출처를 유지한다. 수동 거합 차징 단축이 자동 반격의 기본 집중 시간 1.5초를 바꾸지 않는다.
- 구현 상태: 2026-10-23 가드·쳐내기 중 사용, 일섬 집중 조정·연출·타격 정지는 feature/bullet-time-dash-attack에서 코드와 Player.prefab에 반영했고 C# 빌드 오류 0개다. 이 조정들의 Play 체감은 미확인이다. 2026-10-23 M1 독립 자원 모델과 M2 입력·전투·보상 연결이 완료됐다. Unity 재컴파일 오류 0. Play 평가에서 Shift 일섬 소비와 약 0.21초 집중, Q 거합 자동 차징·일시정지 정지/재개·시전 시 1회 소비, 자원 부족 및 연타 거부, 좌클릭 일반 공격, 비활성화 및 사망 콜백의 시간 요청 해제를 확인했다. 차징 중 사망 콜백 평가에서는 거합 게이지 100%가 유지됐다. 실제 키 장치 입력은 Editor 포커스 문제로 확인하지 못했으며 실제 치명타 발생 통합도 미검증이다. #### 연결 및 협업

- 사용자 승인: 리메이크 계획 실행, luna-max 구현·어려운 통합은 sol 조정자가 직접 수행. 최신 조건은 패링당 정확히 1/3, 보스 일반 공격당 거합 3%p다.
- 최초 M1·M2 작업에서는 온보딩을 제외했으나, 2026-10-23 후속 작업에서 온보딩의 입력·게이지·표시·목표 판정을 같은 규칙으로 연결했다. 온보딩 전용 진행은 [온보딩 명세](온보딩.md)를 따른다. 해당 후속 작업의 Unity 컴파일과 Play 검증은 사용자 요청에 따라 실행하지 않았다.
- 현재 브랜치는 feature/skill이며 Git CLI·커밋·푸시는 수행하지 않는다. Sites/Apps Script 배포는 포함하지 않는다.
- 이전 토큰·홀드 규칙의 날짜별 기능명세는 과거 기록이며 정식 전투의 현재 규칙은 이 문서를 우선한다.
- 2026-10-23 불릿 타임 발도(feature/bullet-time-dash-attack 병합): 패링·극한회피 집중 중 실이 연결된 적이 있으면 좌클릭은 일반 공격 대신 발도 돌진을 요청한다. 돌진이 시작되면 집중을 끝내고 실제 시간으로 돌진·베기하며(Player.prefab `_dashBulletTimeRatio` 0) 게이지는 바꾸지 않는다. 돌진 중 일반 공격 부채꼴 휩쓸기 피해도 `Normal` 문맥이라 보스 적중 보상 대상이다. 일섬 집중·거합 자동 차징 중에는 발도를 허용하지 않는다. 도착 베기(`IaidoFinisher`)의 보스 적중은 기존 규칙대로 거합 +3%p 대상이다. 상세는 [1인칭 근접 교전](1인칭_근접_교전.md)의 2026-10-23 절을 따른다.
