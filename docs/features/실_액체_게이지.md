### 실 액체 게이지(거합 원형 게이지·일섬 토큰 칸)

- 기능 설명: 거합 게이지와 일섬 토큰 세 칸의 빨간 Fill을, 토큰·칼 구슬과 같은 굵은 실 구체 여러 겹이 아래에서 위로 일렁이는 액체처럼 차오르는 표현으로 바꿨다. 실이 겹친 수에 따라 단계별 색을 칠하고, 물결치는 수면에는 실 한 가닥이 놓인다. 가득 차면 테두리를 도는 실과 빛무리가 나타난다(2026-10-23 사용자 요청).
- 동작 조건 및 처리 흐름:
  - 수면: 게이지 값(거합 `UltimateNormalized`, 실제 사용 가능하면 1 / 일섬 칸 `Clamp01(SwordWaveGauge - index)`)을 목표로 `Fill Sharpness`(4)로 차오르고 `Drain Sharpness`(8)로 빠진다. 늘어난 양만큼 출렁임(물결 증폭·기울기)이 생기고, 출렁이는 동안 실과 물결이 빨라진다. 두 사인 물결 식은 C#(`CombatThreadLiquidGauge.SurfaceHeight`)과 셰이더(`BlindBlade/UIThreadLiquid`)가 같다. HUD라 `Time.unscaledDeltaTime`을 쓴다.
  - 액체 본체: `CombatThreadLiquidBody`가 `ThreadSphere` 실 구체 `Layer Count`(3)겹을 겹마다 자전축을 다른 수평축 둘레로 `Layer Tilt`(55°) 기울이고 `Tumble Angle`(30°)까지 뒤척이며 그린다. 실을 `BlindBlade/ThreadLiquidDensity`로 RenderTexture에 한 겹 1/8씩 더해 픽셀마다 겹침 수를 쌓는다(뒤쪽 실은 `Back Opacity` 0.3, 깊은 곳은 `Depth Opacity` 0.45까지 가볍게 센다). 같은 오브젝트의 RawImage가 `BlindBlade/UIThreadLiquid`로 겹침 수를 0~4단계 색(바탕·1·2·3·4겹 이상, 기준 0.25·1.15·2.1·3.05)으로 바꾸고 수면 위와 액체 원 밖을 픽셀 단위로 잘라 낸다. 텍스처 원점이 위인 플랫폼은 밀도 셰이더에서 위아래를 뒤집어 저장한다.
  - 수면·테두리: `CombatThreadLiquidGauge`(MaskableGraphic, 기본 UI 재질)가 본체 위에 수면 실, 고리 빛무리, 테두리 실을 그린다. 끝까지 찬 원은 `Filled Glow Opacity`, 가득 참(거합 100%·일섬 세 칸 모두)은 `Ring Glow Opacity`만큼 맥동하는 고리 빛무리를 낸다.
  - 테두리 실: 굵은 머리 `Rim Head Count`개가 불규칙한 흐름으로 시계 방향으로 돌고, 머리마다 용수철과 지수 분포 간격의 무작위 밀기로 고른 간격 자리에서 앞서거나 처진다(간격의 `Rim Head Wander`배 안, 순서 유지). 머리는 굵은 부분(`Rim Stroke Length`)을 유지하다 마지막 `Rim Taper Length` 구간에서 가늘어지고, 실을 따라 흐르는 두 파동이 굵기를 `Rim Wave Depth`(±50%)만큼 바꾼다. `Rim Connected`면 머리 사이가 `Rim Hairline` 폭의 가는 실로 이어진 한 가닥, 끄면 따로 떨어진 선이다. `Rim When Filled`면 그 원이 끝까지 찼을 때, 끄면 가득 참일 때 나타난다.
  - 거합 게이지: 테두리 실은 가득 참일 때 이어진 한 가닥(머리 3개)이다. 백분율은 흰 글자·외곽선 없음, 100%는 금색이다. 거합 자동 차징·시전(`IsAutomaticCharging`·`IsStriking`, 쌍둥이 자동 역거합 포함) 동안 게이지 캔버스(정렬 101, 암전 연출 100보다 위) 전체를 실시간 0.15초에 걸쳐 숨긴다.
  - 일섬 토큰: 칸마다 본체·게이지를 따로 만든다. 칸이 끝까지 차면 은은한 빛(0.42)과 따로 떨어진 선 두 개가 테두리를 돌고, 세 칸이 모두 차면 빛(0.26)이 더해지며 실 흐름이 2.5배 빨라진다. 이전의 빨간 부분 Fill과 완충 칸 실 구체(`CombatTokenOrbitThread`)는 쓰지 않는다.
- 구현 상태: 2026-10-23 구현. Unity 생성 csproj를 복사한 검증 프로젝트의 `dotnet build` 오류 0개(새 경고는 직렬화 필드 CS0649뿐). Unity 컴파일은 중간 단계(실 줄 액체·픽셀 수면 자르기)까지 확인했고 사용자 Play 피드백으로 조정했다. 겹침 단계 합성·RenderTexture 위아래 방향·이어진 테두리 실·일섬 선 두 개·거합 중 숨김의 최종 Play 확인은 미확인이다.

#### Inspector 설정

- 거합: `Assets/Resources/Prefabs/Player.prefab` → Player Ultimate Hint → "실 액체"(Liquid Density Material, Liquid Composite Material, Liquid Style). 같은 컴포넌트 "게이지 원본 및 배치"에 Value Outline Width 0, Hide Fade Duration 0.15.
- 일섬: `Assets/Scenes/Defense/UI/BambooDefenseHud.prefab` → PerfectParryTokens → Combat Perfect Parry Token Hud → "실 액체". 액체 반지름 0.84(빈 슬롯 바깥 링 안쪽), 텍스처 128, Rim Thread·Rim When Filled 켬, Rim Connected 끔, 머리 2개·길이 0.25·가늘어지는 구간 0.6, Filled Glow Opacity 0.42, Ring Glow Opacity 0.26, 맥동 초당 0.6회.
- 코드 기본값이 Unity에 반영되지 않는 문제를 피하려고 모든 값을 두 프리팹에 직접 적었다.

#### 연결 및 협업

- 연결된 기능: [특수 스킬 게이지](특수스킬_게이지.md)의 거합 원형 HUD와 일섬 3칸, [퍼펙트 패링 토큰](퍼펙트_패링_토큰.md)의 토큰 실 구체(`ThreadSphere`·`ThreadSphereFlow`·`CombatTokenOrbitStyle` 재사용), [전투 HUD](전투_HUD.md)의 PerfectParryTokens, EmpowerOverlay 암전 연출.
- 공유하는 코드 및 상태: `ThreadSphere`·`ThreadSphereFlow`·`CombatTokenOrbitStyle`(칼 구슬·쌍둥이 구슬 HUD와 공유, 수정하지 않음), `PlayerSkillGauge`, `PlayerEmpower.IsAutomaticCharging`·`IsStriking`, Player 프리팹, BambooDefenseHud 프리팹.
- 중복 또는 충돌 사항: M3에서 만든 거합 원형 Fill과 일섬 부분 Fill을 대체했다. `CombatPerfectParryTokenHud`에서 Filled Color·Orbit Style·가득 참 빛무리 설정을 지웠고 Filled Sprite는 거합 배경 대체 Sprite로 남겼다. `CombatTokenOrbitThread`는 `TwinHumanBeadHud`가 계속 쓴다. 3D 칼 구슬(`PlayerKatanaBeads`)은 바꾸지 않았다. 온보딩도 같은 HUD 프리팹을 쓰므로 일섬 칸 표시가 함께 바뀐다.
- 승인 필요 사항 및 결과: 2026-10-23 사용자가 거합 게이지부터 실 액체 적용, 겹침 단계 색, 테두리 실 한 가닥 연결·파동 굵기·무작위 간격, 백분율 흰 글자·외곽선 제거, 거합 중 게이지 숨김, 일섬 적용(다 찬 칸 은은한 빛·선 두 개)을 차례로 요청했다.
