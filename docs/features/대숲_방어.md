# 대숲 방어

## 현재 동작

BambooDefenseDirector가 일반 방어 웨이브의 준비 시간, 생존 시간, 처치 수, 처치 목표와 공격 차례 제한을 관리한다. DefenseEnemySpawner는 근접 적·Beast·투척수를 생성하고, 적 사망과 디스폰을 Director 및 텔레메트리에 전달한다. 대숲 1막과 비 내리는 2막은 이 공용 방어 시스템을 사용한다. DefenseRecordHud는 처치 목표가 있을 때 화면에 보이는 처치 수만 0부터 목표까지 제한한다. 실제 처치 수는 Director에 그대로 보존되며, 목표가 없는 씬은 실제 처치 수를 표시한다.

## 현재 정식 씬의 스폰 설정

씬에 저장된 Inspector 값을 기준으로 한다. 코드의 초기값은 씬에서 덮어쓸 수 있으므로 정식 게임 동작은 씬 직렬화값을 우선한다.

| 설정 | BambooStage1 | RainyTwinBoss |
| --- | ---: | ---: |
| 보스 등장 처치 목표 | 100명 | 100명 |
| 근접 등장 시작 시각 | 웨이브 시작 즉시 | 웨이브 시작 즉시 |
| 근접 첫 1분 평균 스폰 시도량 | 70회 | 70회 |
| 근접 스폰율 1분 배율 | 1.35 | 1.35 |
| 근접 동시 생존 상한 | 200명 | 200명 |
| 근접 총 생성 상한 | 제한 없음(0) | 제한 없음(0) |
| 투척수 시작 시각 | 웨이브 시작 즉시 | 웨이브 시작 5초 뒤 |
| 초기 투척수 | 1명 | 1명 |
| 투척수 목표 증가 | 분당 2명 | 분당 3명 |
| 투척수 동시 상한 | 6명 | 6명 |
| 투척수 최소 생성 간격 | 1.33초 | 1.33초 |
| 근접 적 종류 | DefenseMelee만 | DefenseMelee와 DefenseBeast |
| 근접 발자국 표시 | 켜짐 | 꺼짐 |

근접 스폰율은 일정한 100회/분이 아니다. R을 첫 1분 평균 목표량, g를 1분 배율, t를 근접 스폰 시작 뒤 경과 분으로 두면 현재 스폰율은 R × ln(g)/(g−1) × g^t이다. g가 1이면 고정 R을 사용한다. 현재 두 씬은 R=70, g=1.35이므로 시작 시 약 60회/분에서 출발해 시간이 지나며 증가한다. 이 수치는 스폰 시도율이며 동시 생존 상한, 위치 탐색 실패와 처치 목표에 따라 실제 등장 수는 달라진다.

근접 적의 동시 생존 상한과 누적 생성 제한은 별개다. Maximum Melee는 동시에 살아 있는 근접 적 수를 제한하고, Melee Spawn Limit은 웨이브 전체 누적 생성 수를 제한한다. Melee Spawn Limit 0은 누적 제한이 없다는 뜻이다. 두 Stage Controller는 처치 목표를 Director에 전달하지만 이를 총 생성 제한으로 바꾸지 않는다. 목표 처치에 도달하면 웨이브를 멈추고 살아 있는 웨이브 적과 비행 중인 일반 수리검을 정리한다. 이 정리는 처치로 집계하지 않는다.

RainyTwinBoss의 근접 적 선택 비율은 성공적으로 생성한 수를 기준으로 0~100마리 구간에서 선형 보간한다. 0마리에서는 일반 적 30%·Beast 70%, 100마리에서는 일반 적 70%·Beast 30%다. 100마리 이후에도 끝 비율을 유지한다. BambooStage1에는 Beast 프리팹이 연결되어 있지 않아 일반 근접 적만 생성한다.

두 정식 씬의 공통 최소 플레이어 거리는 13m다. 근접 적 후보 위치는 지정 스폰 반경에서 찾고, 투척수도 플레이어와 최소 거리를 만족해야 생성된다. 실제 위치는 NavMesh와 밀집도 검사 결과에 따라 달라진다.

## 적과 투사체 수명

- 근접 적과 Beast는 DefenseEnemySpawner의 종류별 대기 스택으로 재사용한다. 사망 또는 웨이브 종료 시 비활성화해 풀로 돌려보낸다. 이 풀은 현재 최대 동시 수만큼 미리 생성하는 pre-warm을 하지 않는다.
- BambooThrower도 비활성화된 인스턴스를 재사용한다. 투척수는 수리검을 발사한 뒤 디스폰될 수 있으며, 비행·유도·충돌·수명은 DefenseShuriken이 관리한다.
- DefenseShuriken은 적과 다른 수리검을 비행 중 충돌 대상으로 삼지 않는다. 벽·지형·플레이어와의 접촉 및 수리검 상태에 따라 자체 비행 또는 반사 수명을 종료한다. 웨이브 종료 시 Director가 해당 씬의 적대 비행 수리검을 명시적으로 해제한다.
- 근접 적은 물리 몸체 Collider 대신 EnemyHitCapsule을 이용해 플레이어 공격을 판정한다. 일반 DefenseMelee의 몸 막힘은 코드 이동 처리로 유지되고 Beast의 몸 막힘 규칙은 별도로 설정된다. 투척수와 보스는 몸체 충돌체를 보유한다.

## 연결 및 확인 상태

전투 HUD, 공격 전조 방향 표시, 발소리 후보, 소리 인지, 적 공격 차례와 텔레메트리가 Director·Spawner의 이벤트를 구독한다. 세부 규칙은 각 기능 명세를 따른다.

이번 문서 갱신에서는 코드와 두 정식 씬의 직렬화 값을 대조했다. Unity Play에서 스폰 체감, 풀의 장시간 안정성, 프레임 성능은 확인하지 않았다.
