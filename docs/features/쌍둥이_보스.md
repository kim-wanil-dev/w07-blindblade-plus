#### 패턴 규칙

- 둘 다 생존하면 탑승 사격·인간 사격·짐승 지그재그·짐승 점프를 가중치로 선택한다. 인간만 생존하면 사격, 짐승만 생존하면 지그재그·점프만 선택한다. 유효 가중치가 모두 0이면 인간 생존 시 사격, 짐승만 생존 시 지그재그를 사용한다.
- 협력 중 인간은 짐승의 RiderSeat를 따라가며 원형 이동과 연사를 병행한다. 반사탄 또는 일반 공격으로 실제 피해가 들어오면 파훼·하차·지상 회피·회복 후 다음 패턴을 선택한다. 일반 가드는 탄환을 제거하고 패링만 발사자를 추적하는 반사탄으로 전환한다.
- 제한 시간이 끝나면 남은 탄환·사격·원형 이동을 정리하고 탑승 상태의 점프 한 번으로 마무리한다. 협력 중 한쪽 사망은 현재 패턴을 취소한다. 개별 패턴도 보스 사망 시 취소 후 생존 조건으로 다시 선택한다.
- 인간과 짐승은 서로의 자식이 아닌 별도 루트이며 제어자는 두 루트 밖에 둔다. 인간 하차 시 좌우의 빈 NavMesh 위치를 검사하며 둘 다 막혔으면 탑승 전 지면으로 복귀한다.
- 지그재그는 전조 후 목표 방향을 고정하고 좌우 목표를 번갈아 향한다. 장애물·NavMesh 경계·이동 구간 접촉을 검사하고 가드·패링·피해 중 하나를 한 번 처리하면 종료한다.
- 점프는 전조 종료 시 목표 위치를 고정하고 유효한 지면·직선 이동 공간을 확인한다. 포물선 이동 중 장애물이 생기면 취소하며, 착지 반경 안에 피해를 한 번 적용한다. 점프 종료·취소 시 NavMesh 설정을 복원한다.
- 짐승 두 공격도 기존 TryDefendProjectile의 방향 기반 방어 계약을 재사용해 전방 가드·패링을 허용한다. 패링에 별도 스턴을 추가하지 않는다. 플레이어 사망·전투 비활성화 시 진행 중 공격과 탄환 및 구독을 정리한다.
- 인간 사격 전조와 짐승 공격 전조는 설정한 SoundId를 재생한다. 전용 애니메이션·정식 모델·새 사운드 자산은 추가하지 않았으며 각 공격·착지·파훼 이벤트를 제공한다.
