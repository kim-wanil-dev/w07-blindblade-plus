### 비 내리는 쌍둥이 보스전

- 기능 설명: RainyStage를 복제한 `RainyTwinBoss` 씬에서 일반 적 웨이브 없이 바로 쌍둥이 보스(TwinBoss) 보스전을 진행한다. 비 연출은 RainyStage와 같다.
- 동작 조건 및 처리 흐름: `RainyTwinBossController.Start`가 `BambooDefenseDirector.StopWave`·`HideRecord`로 방어 웨이브와 처치 기록을 끈다. GameplayState가 Playing이 되면 `강적 출현` 경고를 2초 표시하고, 원형 공터(`Arena`, Edge Inset 2m)의 NavMesh 후보 중 플레이어에서 가장 먼 지점을 찾는다. 그 지점을 중심으로 플레이어를 향한 좌우(Pair Gap 4m)에 인간·짐승을 배치하고 비활성이던 TwinBoss 루트를 켠다. 좌우 위치가 NavMesh에 없으면 중심 지점을 사용한다. 등장 순간 플레이어 HP를 최대로 회복하고, Stage1과 같은 빨간 등장 파동 3회와 카메라 흔들림을 재생한다. 전투 패턴은 기존 `TwinBossController`가 시작한다. 인간·짐승의 `EnemyHealth.Died`를 구독해 둘 다 쓰러지면 `GameStateManager.RequestGameClear`로 게임 클리어 화면을 연다. 플레이어 사망은 기존 게임오버 흐름이며 재도전은 현재 씬을 다시 로드해 경고부터 다시 시작한다.
- 구현 상태: 씬 복제, 전용 컨트롤러, 인간·짐승 체력바 2개 연결을 구현했다. 빌드 목록·인트로·Stage1 연결은 사용자 결정으로 하지 않았으며 에디터에서 씬을 열어 직접 Play한다. 쌍둥이 보스의 연기 외형과 도형 늑대는 [쌍둥이 보스](쌍둥이_보스.md)의 2026-10-17 절을 따른다.

#### 연결 및 협업

- 연결된 기능: [RainyStage 비 연출](RainyStage_비_연출.md), [쌍둥이 보스](쌍둥이_보스.md), [대숲 스테이지 1](대숲_스테이지1.md)(등장 연출 방식 참고), 게임오버 재도전, 게임 클리어 화면.
- 공유하는 코드 및 상태: 경고 Canvas·Arena·Director·등장 파동 프리팹·`RainStageWeather` 설정은 RainyStage 복제본의 것을 사용한다. 보스 체력·사망은 각 `EnemyHealth`가 소유한다.
- 중복 또는 충돌 사항: `BambooStage1Controller`와 등장 위치 탐색·파동·흔들림 코드가 유사하지만, Stage1 동작과 체크포인트(`BambooStage1Progress`)에 영향을 주지 않도록 별도 클래스로 두었다. 이 씬은 Stage1 체크포인트를 읽거나 쓰지 않으며 텔레메트리 Stage 신호도 보내지 않는다(Recorder는 `unassigned`로 기록). TwinBoss에는 `BossController.ConfigureArena` 같은 공터 이동 제한이 없어 회피·점프 목적지가 공터 밖 NavMesh로 갈 수 있다(미확인). RainyStage 씬은 변경하지 않았다. TwinBoss 프리팹의 외형 변경은 쌍둥이 보스 명세에 기록한다.
- 승인 필요 사항 및 결과: 2026-10-17 사용자가 RainyStage 복제, 웨이브 없이 바로 보스전, 빌드 목록·진입 경로 연결 없음을 선택했다.

#### Inspector 설정

- `RainyTwinBossController`: Warning Duration 2초, Edge Inset 2m, Spawn Sample Radius 2m, Pair Gap 4m. 등장 파동(반경 48m·굵기 2m·3회·0.32초 간격·1.5초)과 흔들림(0.13·0.55초·24Hz)은 Stage1과 같은 값을 씬에 저장했다.
- 체력바: Human Top Offset 72, Beast Top Offset 96, 크기 420x16, 지연 바 빨간색.

#### 확인 결과

- `dotnet build Assembly-CSharp.csproj --no-restore` 오류 0개, 기존 경고 2개(CS0414). Unity가 아직 새 파일을 가져오지 않아 생성 파일인 csproj에 새 스크립트 Compile 항목 한 줄을 직접 추가해 빌드했다.
- 씬 YAML은 RainyStage 대비 보스 인스턴스·컨트롤러 블록만 다르며 CRLF 유지와 파일 ID 중복 없음을 확인했다.
- Unity 에디터 로그에서 새 스크립트 컴파일과 씬 가져오기·열기를 확인했다. 사용자 Play에서 트윈보스가 등장해 인간 사격(`TwinBossRanged` 15 피해)이 플레이어에 적중한 기록을 확인했다.
- 같은 Play를 끌 때 씬 해제 순서로 경고 Canvas가 먼저 파괴되어 `OnDisable`에서 MissingReferenceException이 났다. Canvas가 남아 있을 때만 숨기도록 수정했으며 수정 후 Play 종료는 미확인이다. 같은 코드가 있는 `BambooStage1Controller`는 범위 밖이라 변경하지 않았다.
- 두 보스 처치 후 클리어, 사망 후 재도전은 Play 미확인이다. 테스트 코드는 작성하지 않았다.
