# 비 내리는 쌍둥이 보스전

## 현재 구현

RainyTwinBoss 씬의 쌍둥이 보스는 인간형과 Beast가 한 쌍으로 동작한다. 두 EnemyHealth는 공유 체력 350을 사용한다. 보스전 시작 전에는 보스 루트가 비활성화되어 있으며 RainyStageController가 일반 웨이브 완료, 등장 경고, 배치와 클리어를 관리한다.

일반 적 100명을 처치하면 2초 경고 후 플레이어와 경로가 연결된 공터 안 NavMesh 위치에 두 보스를 배치한다. 두 보스는 플레이어를 향해 나란히 등장하고 간격은 4m다. 플레이어 체력은 등장 시 최대로 회복된다. 붉은 등장 파동이 끝날 때까지 보스 행동을 보류하고, 대기 시간은 파동 설정에서 계산한다.

보스 이동과 돌진·회피 목적지는 원형 공터 안쪽으로 제한된다. 인간과 Beast의 공격 패턴, 공통 공격 식별·피해·피격 판정은 각 보스와 전투 계약의 기능을 사용한다. 두 보스 모두 사망하면 3초짜리 소멸 연출이 진행되고 게임 클리어 UI가 같은 3초 뒤 표시된다. 클리어 상태에서도 전투 시간 배율은 바꾸지 않고 게임플레이 입력을 종료하며 커서를 표시한다.

## 연결

스테이지 웨이브와 씬 저장값은 [비 내리는 스테이지 2](비_스테이지2.md), 개별 보스 패턴은 [쌍둥이 보스](쌍둥이_보스.md), 클리어 UI는 [게임 클리어 화면](게임_클리어_화면.md)을 따른다.

## 확인 상태

보스 프리팹의 공유 체력, 씬의 100명 처치 목표와 등장 설정, 코드 연결을 확인했다. 실제 보스전의 전투 흐름과 화면 연출은 이번 문서 갱신 과정에서 Play 검증하지 않았다.
