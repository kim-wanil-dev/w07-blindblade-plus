#### ParrySuccess·GuardSuccess FMOD 변경 반영 (2026-10-15)

- FMOD Studio의 저장된 `ParrySuccess`·`GuardSuccess` 이벤트 변경 시각이 기존 `SFX.bank` 빌드보다 늦어, Unity가 이전 뱅크를 읽고 있었다. FMOD Studio 2.03.15 CLI로 Desktop 뱅크를 다시 빌드하고 `Assets/StreamingAssets`에 복사했다. `SFX.bank` 크기는 970112→999488바이트로 바뀌었고, 복사본 네 개의 해시는 각 원본 뱅크와 일치한다.
- Unity FMOD 설정은 `FMODProject/week06-blindblade/Build`를 소스로 사용하는 StreamingAssets 방식이며 Master·BGM·SFX 뱅크 자동 로드다. SoundLibrary와 CombatSoundProfile은 기존 두 이벤트의 경로·GUID를 그대로 참조한다. 재생 호출과 볼륨 설정은 변경하지 않았다.
- `.gitignore`의 FMOD 생성 폴더 제외 경로를 실제 중첩 프로젝트에 맞게 고쳤다. 기존 Git 추적 대상이던 `.cache` 376개는 사용자가 이번 작업에 한해 허용한 `git rm --cached`로 추적만 해제했다. Git에는 해당 376개 삭제가 스테이징되어 있지만 실제 캐시 파일은 디스크에 남아 있고 FMOD가 계속 재생성할 수 있다. FMOD 원본 음원·Metadata·Build/Desktop 뱅크는 추적 대상에 남겼다. 이 브랜치에서 커밋은 하지 않았다.
- 빌드는 기존 압축·스트리밍 충돌 경고를 허용해 성공했다. Unity Editor가 실행 중이지 않아 Editor 뱅크 새로고침과 실제 가드·패링 청취는 미확인이다.

#### 편집 및 청취 순서

1. Unity 메뉴의 BlindBlade/사운드 편집을 연다.
2. 해당 상황을 펼쳐 SoundId 또는 직접 FMOD 이벤트, 음량, pitch, 파라미터 이름·Label을 편집한다.
3. 베기 시간 보정은 기존 베기 구간 시작에 더한다. 음수는 앞당김이며 행동 시작 이전은 0초로 제한한다. 발도·접촉·피격은 사건 이후 양수 지연만 적용한다. 음원 자체의 무음 구간은 FMOD에서 조정한다.
4. 변경한 타이밍은 다음 행동 예약부터 적용한다. 미리 듣기는 음원·pitch·Label을 확인하며 행동 시간·게임 공간 믹싱을 재현하지 않는다.
5. 상황에 음원 추가로 같은 상황의 다른 음원을 겹쳐 재생할 수 있다. 새 항목은 비활성으로 추가된다. 마지막 항목을 삭제하면 해당 상황은 무음이다.
6. Play 후 실제 재생 기록에서 상황·이벤트·발음체·Label·음량을 확인한다. 편집 중 변경은 설정 저장으로 이 두 사운드 에셋만 저장한다. 다른 씬·에셋은 저장하지 않는다.
