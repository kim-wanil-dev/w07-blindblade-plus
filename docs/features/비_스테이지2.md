# 비 내리는 스테이지 2

## 현재 진행

RainyTwinBoss는 빌드의 2막 정식 씬이다. RainyStageController의 코드 기본 처치 목표는 50명이지만 현재 씬 저장값은 100명이며 실행 시 씬 값이 적용된다. 정상 진입 시 2막 제목을 표시하고 일반 웨이브를 시작한다. 저장된 보스 체크포인트가 있거나 씬의 시작 시 즉시 보스전 옵션이 켜져 있으면 웨이브를 건너뛴다. 현재 씬 저장값에서 즉시 보스전은 꺼져 있다.

일반 적 100명을 처치하면 웨이브를 종료하고 2초 보스 경고를 표시한다. 경고가 끝나면 원형 공터 안의 유효 NavMesh 지점에 인간·짐승 보스를 서로 4m 간격으로 배치하고 플레이어 체력을 최대로 회복한다. 붉은 등장 파동이 끝날 때까지 보스 행동은 대기한다. 두 보스가 모두 사망하면 3초 소멸 연출이 진행되고 게임 클리어 화면이 표시된다.

## 씬에 저장된 스폰·처치 설정

| Inspector 값 | 현재 값 |
| --- | ---: |
| Required Kills | 100 (씬 저장값, 코드 기본값 50) |
| Melee Start Time | 웨이브 시작 즉시 |
| Melee Spawns Per Minute | 70회, 첫 1분 평균 목표 |
| Melee Spawn Multiplier Per Minute | 1.35 |
| Maximum Melee | 동시 생존 200명 |
| Melee Spawn Limit | 0, 누적 생성 제한 없음 |
| Minimum Spawn Distance | 13m |
| Melee Spawn Radius | 22.5~23.4m |
| Thrower Start Time | 웨이브 시작 5초 뒤 |
| Initial Throwers | 1명 |
| Throwers Per Minute | 목표 동시 수 분당 3명 증가 |
| Maximum Throwers | 6명 |
| Thrower Spawn Interval | 1.33초 |

근접 스폰율은 고정 100회/분이 아니다. 첫 1분 평균 70회와 1분 배율 1.35를 사용해 시간이 흐르며 증가한다. 처치 목표와 누적 생성 상한은 별도 설정이므로 목표 처치 전에는 100명보다 많이 생성될 수 있다. 목표 달성 시 웨이브 종료가 스폰을 멈춘다.

근접 적 종류는 성공적으로 생성한 수 0~100마리 사이에서 가중치를 선형 보간한다. 시작은 일반 DefenseMelee 30%·DefenseBeast 70%, 끝은 일반 70%·Beast 30%이며 100마리 뒤에는 끝 비율을 유지한다. 수리검 투척수의 생성 목표는 별도 필드로 관리하며 근접 스폰율·가중치와 연동하지 않는다.

## 비·HUD 연결

RainyTwinBoss 씬의 RainStageWeather는 일반 웨이브에서 가까운 빗방울 1,434개, 보스전에서 2,662개를 사용한다. 바깥 고리 빗방울 수는 별도 설정이다. RainyStageAudio가 씬의 비 사운드를 관리한다.

정식 씬의 DefenseDirector는 적 공격 전조 표시를 사용한다. 화면 밖 DefenseMelee 공격 시도는 쌍검, DefenseBeast의 물기 공격 시도는 이빨 표시로 나타난다. 적 발소리·월드 발자국·보스 및 수리검 방향 표시의 세부 규칙은 [전투 HUD](전투_HUD.md)를 따른다.

## 확인 상태

빌드 씬 등록, 씬 저장값, 프리팹 연결과 주요 코드 경로를 확인했다. Unity Play에서 현재 스폰 밀도·전조 UI·비 표현·최종 클리어 동작은 이번 문서 갱신 과정에서 확인하지 않았다.
