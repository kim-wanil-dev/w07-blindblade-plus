# 게임 클리어 화면

## 현재 동작

2막 쌍둥이 보스가 모두 사망하면 RainyStageController가 GameStateManager를 Cleared 상태로 전환하고 커서를 표시한다. 게임플레이 입력을 종료하지만 전투 세션의 시간 배율은 변경하지 않는다. GameClearUI는 타이틀 복귀 패널을 표시하고 타이틀 버튼을 선택 상태로 둔다.

GameClearUI의 기본 표시 대기값은 1.25초다. 정식 RainyTwinBoss 흐름은 보스 소멸 연출 길이인 3초를 다음 표시 대기값으로 지정하므로 최종 보스 사망 뒤 3초 후 패널이 열린다. 대기와 표시는 실제 시간 기준이라 게임 시간 배율의 영향을 받지 않는다. 타이틀 복귀는 IntroScene으로 페이드 전환한다.

## 관련 코드

| 파일 경로 | 클래스 / 메서드 | 역할 |
| --- | --- | --- |
| Assets/Scripts/Defense/RainyStageController.cs | HandleBossDied | 쌍둥이 보스 최종 사망 시 3초 표시 대기 설정 |
| Assets/Scripts/GameManagers/GameStateManager.cs | RequestGameClear | Cleared 상태와 커서 표시, 게임 시간 배율 유지 |
| Assets/Scripts/GameManagers/GameClearUI.cs | SetNextDisplayDelay, HandleStateChanged, ShowAfterDelay, ReturnToTitle | 표시 대기·버튼 선택·타이틀 복귀 |
| Assets/Scripts/Enemies/BossDeathDissolve.cs | DURATION | 최종 보스 소멸 시간 |

## 연결 및 확인 상태

[비 내리는 스테이지 2](비_스테이지2.md)에서 최종 사망 시 표시 대기값을 설정한다. 기본 지연값과 정식 스테이지의 지연값은 서로 다를 수 있다.

이번 문서 갱신에서는 소스 코드의 상태 전환, 표시 지연과 씬 이름을 확인했다. 실제 UI 포커스·버튼 입력·씬 전환은 Play로 확인하지 않았다.
