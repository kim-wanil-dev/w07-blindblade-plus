### 게임 클리어 화면

- 기능 설명: 정식 진행에서는 RainyTwinBoss의 쌍둥이 보스 둘을 처치하면 게임 입력을 멈추고 클리어 패널과 타이틀 복귀 버튼을 표시한다.
- 동작 조건 및 처리 흐름: `GameStateManager.RequestGameClear`가 Cleared 상태를 설정하며 커서 잠금 해제와 표시를 적용한다. 클리어 상태의 게임 씬이 닫힐 때도 커서를 표시 상태로 유지한다. 타이틀 씬의 `IntroMenu`가 활성화되면 커서를 다시 해제·표시해 메뉴에서 바로 조작할 수 있게 한다.
- 구현 상태: 클리어 진입 시 및 클리어 뒤 타이틀로 돌아온 뒤 커서를 표시하도록 수정했다. 실제 런타임 화면 확인은 미실시다.

#### 관련 코드

| 파일 경로 | 클래스 / 메서드 | 역할 |
| --- | --- | --- |
| Assets/Scripts/Defense/RainyStageController.cs | HandleBossDied | 쌍둥이 보스 둘의 사망을 게임 클리어 상태로 전달 |
| Assets/Scripts/GameManagers/GameStateManager.cs | RequestGameClear, RestoreTimeAndCursor, Shutdown | 클리어 정지·커서 표시 및 씬 종료 상태 복구 |
| Assets/Scripts/GameManagers/GameClearUI.cs | HandleStateChanged, SetVisible, ReturnToTitle | 클리어 패널·타이틀 복귀 버튼 |
| Assets/Scripts/UI/IntroMenu.cs | Awake | 타이틀 메뉴 진입 시 커서 표시 |

#### 연결 및 협업

- 연결된 기능: [대숲 스테이지 1](대숲_스테이지1.md), [비 내리는 스테이지 2](비_스테이지2.md), [인트로 메뉴](인트로_메뉴.md), [게임오버 재도전](게임오버_재도전.md).
- 공유하는 코드 및 상태: `GameStateManager`가 플레이·클리어 상태와 게임 시간 수명을 관리한다. `IntroMenu`는 타이틀 메뉴가 활성화될 때 커서를 표시한다.
- 중복 또는 충돌 사항: 게임오버 재도전 시에는 기존 커서 복구 동작을 유지하고, Cleared 상태로 씬이 닫힐 때에만 커서를 보이게 한다.
- 승인 필요 사항 및 결과: 사용자 요청에 따라 클리어 패널과 타이틀 복귀 경로의 커서 표시를 보정했다.
