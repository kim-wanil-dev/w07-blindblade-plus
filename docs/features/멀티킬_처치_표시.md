# 멀티킬 처치 표시

- 기능 설명: 온보딩을 제외한 HUD 연결 방어 씬에서 일반 공격, 일섬 또는 거합 한 번으로 5명 이상을 실제 처치하면 처치 목표 아래에 `+N`을 표시한다. 현재 연결 씬은 BambooStage1, BambooDefense, RainyStage_JH, RainyTwinBoss, TestStage와 (Legacy) RainyStage다.
- 동작 조건 및 처리 흐름:
  - `DefenseEnemySpawner`가 처치 목표에 집계하는 근접 적의 사망만 전달한다. 온보딩, 보스 진입 후, 출처 없는 피해, 디스폰은 새 멀티킬에 포함하지 않는다.
  - `EnemyHealth`는 실제 치명타 `DamageContext`를 사망 처리 전에 저장한다. 사망 시점의 플레이어 행동을 조회하지 않는다.
  - 일반 공격과 IaidoFinisher는 기존 행동 ID를 사용한다. 일섬의 돌진과 비행 검기는 전용 음수 실행 ID를 공유하며, 거합은 한 번 시전마다 별도 실행 ID를 받는다.
  - 실행별 처치는 분리해 센다. 표시 대상은 최신 결과와 직전 결과 두 줄이며, 이전 실행의 늦은 처치는 이전 숫자만 갱신한다. 퇴장한 결과는 다시 나타나지 않는다.
  - 공용 `BambooDefenseHud.prefab`의 루트 `DefenseMultiKillHud` Inspector에서 `등급`의 시작 처치 수·색상·크기, `표시 시간`의 수명·갱신 간격, `표시 크기와 배치`의 글자 크기·줄 배치·확대 연출을 조절한다. 모든 연결 씬이 같은 기본 설정을 사용한다. 기본 등급은 5·10·20·30명, 유지 시간은 1.5초(30명 이상 2초), 퇴장은 0.35초다.
  - 두 TMP 슬롯은 Bold를 끈 일반 글자 두께(400)를 사용한다. 전용 TMP SDF 머티리얼의 Underlay로 글자 면 바깥쪽에 검은색 테두리를 그린다. 등급 색상은 글자 면에만 적용하며 테두리도 글자와 함께 페이드한다. 테두리 색·두께는 `ChosunCentennial_otf SDF - MultiKill Black Outline.mat`의 Underlay Color·Dilate에서 조절한다.
  - 일시정지 메뉴 동안 표시 시간과 애니메이션은 멈춘다. 처치 목표가 보스 때문에 숨겨져도 이미 표시된 결과는 자체 수명이 끝날 때까지 남는다.
  - 멀티킬 표시가 웨이브·보스 진행을 대기시키지 않는다. 보상음은 미정이라 추가하지 않았다. 온보딩 문구는 변경하지 않았다.
- 구현 상태: BambooStage1, BambooDefense, RainyStage_JH, RainyTwinBoss, TestStage, (Legacy) RainyStage 씬에 연결했고, 온보딩은 제외했다. 두 TMP 슬롯은 BambooDefenseHud 프리팹에, 검은 바깥 테두리는 전용 TMP 머티리얼에 저장했다. 코드·프리팹·씬 참조는 작성했지만 Unity Editor 6000.3.22f1이 설치되어 있지 않아 Unity 컴파일과 Play 검증은 미확인이다. 30명 이상에는 별도 붓질 이미지를 추가하지 않고 색상·크기 등급만 적용했다.

#### 연결 및 협업

- 연결된 기능: 대숲 스테이지 1, 처치 목표, 일섬, 거합, 공유 체력 적, 전투 HUD.
- 공유하는 코드 및 상태: `DamageContext.AttackId`, `EnemyHealth.Died`, `DefenseEnemySpawner.EnemyKilled`, `BambooDefenseDirector.IsRecordHidden`.
- 중복 또는 충돌 사항: 기존 피해량, 사망 이벤트 구독 순서, 처치 목표, 게이지 보상과 텔레메트리 처리는 유지한다. 멀티킬 집계는 기존 처치 이벤트에 문맥을 더해 별도로 전달한다.
- 승인 필요 사항 및 결과: 없음. 보상음 선택과 30명 이상 장식의 화면 튜닝은 추후 결정한다.
- 검증 상태: Unity Editor가 없어 컴파일·Play 항목은 미확인이다. 계획 문서의 수동 검증 목록을 참조한다.
