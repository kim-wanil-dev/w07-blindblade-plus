# 멀티킬 처치 표시

## 현재 동작

온보딩을 제외하고 DefenseMultiKillHud가 연결된 방어 HUD에서 일반 공격, 일섬 또는 거합 한 번으로 근접 적을 5명 이상 처치하면 처치 기록 아래에 추가 처치 수를 표시한다. 공격 실행 ID로 처치를 묶으므로 서로 다른 공격의 처치는 합산하지 않는다. 늦게 확정된 처치는 해당 공격 결과를 갱신한다.

HUD는 최신 결과와 직전 결과 두 줄을 표시한다. 표시 중 일시정지되면 수명과 애니메이션도 멈춘다. 보스 진입으로 처치 기록이 숨겨져도 이미 표시된 결과는 자체 수명이 끝날 때까지 남는다. 기본 등급 경계는 5·10·20·30명이며, 표시 시간은 일반 등급 1.5초·30명 이상 2초, 퇴장 시간은 0.35초다.

공용 BambooDefenseHud 프리팹에서 등급별 시작 처치 수·색상·크기와 표시 시간·배치를 조절한다. TMP 텍스트는 전용 SDF 머티리얼의 검은 Underlay 테두리를 사용한다.

## 구현 연결

| 파일 경로 | 역할 |
| --- | --- |
| Assets/Scripts/Enemies/EnemyHealth.cs | 사망 시 실제 치명타 피해 문맥을 보존 |
| Assets/Scripts/Defense/DefenseEnemySpawner.cs | 웨이브 근접 적의 사망 문맥 전달 |
| Assets/Scripts/Defense/BambooDefenseDirector.cs | 일반 웨이브 사망을 HUD로 전달 |
| Assets/Scripts/Defense/DefenseMultiKillHud.cs | 실행별 집계와 두 결과 슬롯 표시 |
| Assets/Scripts/Combat/MultiKillAttackRuntime.cs | 일섬·거합 공격 실행 ID 수명 |
| Assets/Scripts/Player/PlayerSwordWaveLauncher.cs | 일섬 돌진·검기의 공통 실행 ID |
| Assets/Scripts/Player/PlayerEmpowerStrike.cs | 거합 공격 실행 ID |
| Assets/Scenes/Defense/UI/BambooDefenseHud.prefab | 공유 HUD 슬롯과 표시 설정 |
| Assets/Editor/BambooDefenseHudAuthoring.cs | 씬 Director와 HUD 연결 |

정식 빌드 씬 BambooStage1과 RainyTwinBoss는 공유 방어 HUD를 사용한다. 다른 방어·시험 씬 중 같은 HUD가 연결된 씬에도 표시가 적용된다. 온보딩에서는 표시하지 않는다.

## 연결 및 확인 상태

처치 목표 및 전투 피해 문맥을 재사용하며 피해량이나 게이지 보상은 변경하지 않는다. 저장소의 코드·프리팹 연결은 확인했다. Unity Play에서 등급별 표시와 일시정지 동작은 이번 문서 갱신 과정에서 확인하지 않았다.
